# UBrain — 统一调度大脑（产品规格 v1）

> **对外名称建议**：优丁助手 / 卖货副驾  
> **定位**：全站唯一 AI 入口，**越用越聪明**，但不替代人签字与支付  

---

## 一、解决什么问题

| 用户痛 | 现在 | UBrain 后 |
|--------|------|-----------|
| 菜单太多不知道点哪 | 自己找 | 说人话就执行 |
| 重复填平台/国家/模板 | 每次表单 | 记住上次选择 |
| 新人不会回询盘 | 培训成本高 | 生成回复草稿 |
| 老板要看进度 | 多页翻 | 「发布好了吗」一句答 |

---

## 二、产品形态

### 2.1 入口（唯一）

- **租户 Client**：右下角悬浮钮 + 快捷键 `/`  
- **Ops**：顶栏「助手」  
- **Platform**：仅运维模式（查任务、重试队列），不对外租户  

### 2.2 对话示例

```
用户：把昨天美国那条询盘用英文回一下，语气专业
UBrain：已草拟回复 [预览] → 确认发送？

用户：把混凝土 A 型发到上次选的平台
UBrain：将发往 抖音/B2B/… 共5个，预计3分钟 [确认]

用户：我的域名 SSL 好了没
UBrain：shop.xxx.com 已签发，过期日 2026-08-01
```

### 2.3 不能做的事（合规）

- 不自动扣款、不改套餐、不删租户  
- 不跨租户读数据  
- 政府/融资材料生成需标注「AI 草稿」

## 三、技术架构（落在现仓库，不重造）

```
用户输入
   │
   ▼
┌──────────────────────────────────────┐
│  UBrain Orchestrator (新建服务层)      │
│  意图识别 → 策略选择 → 工具调用 → 汇总  │
└──────────────┬───────────────────────┘
               │
     ┌─────────┼─────────┬─────────────┐
     ▼         ▼         ▼             ▼
 询盘API   发布API   域名/SSL API   知识库RAG
     │         │         │             │
     └─────────┴─────────┴─────────────┘
               │
     ┌─────────▼─────────┐
     │ Memory Store      │
     │ 租户级偏好/模板    │  ← 脱敏、可删、可导出
     └───────────────────┘
```

**复用现有**：

- `backend/app/api/v1/agent-hub`、LangChain RAG（超管已有）  
- `InquiriesUnifiedService`、`content_master`、发布 Worker  
- 模型路由：`super-admin/ai-config`  

**新建（分阶段）**：

| 模块 | 路径建议 | 阶段 |
|------|----------|------|
| 对话 API | `POST /api/v1/ubrain/chat` | v1 |
| 工具注册表 | `backend/app/services/ubrain/tools/*.py` | v1 |
| 租户记忆 | `ubrain_tenant_memory` 表 | v2 |
| 反馈学习 | 点赞/修改 → 模板权重 | v2 |
| 工作流 | 报价审批、发布二审 | v3 |

## 四、「越用越聪明」定义（可验收）

| 层级 | 行为 | 数据 |
|------|------|------|
| L0 | 单次任务完成 | 无记忆 |
| L1 | 记住上次平台勾选、常用回复语气 | 租户 KV |
| L2 | 根据行业自动推荐标题结构 | 匿名聚合模板 |
| L3 | 审批流与异常自动建议 | 需人工开通 |

**禁止**：用租户明文询盘训练公共模型；**默认关闭** L2 跨租户。

## 五、与「222 智能体」关系

- **Agency/ECC**：研发内部编排，用户不可见  
- **UBrain**：**用户可见的唯一大脑**，内部可调用「工具」等价于调用子能力  
- 文档 `docs/10-AI智能体系统配置.md` 描述研发侧；本文描述 **产品侧**

## 六、版本计划

### v1（8～10 周）— 能演示给投资人

- 意图：查询盘、草拟回复、查发布状态、查 SSL  
- **出海参谋（M0）**：`export_feasibility` / `blue_ocean` / `hs_suggest`（规则矩阵 + building-wiki，见 `docs/出海参谋-贸易情报与UBrain.md`）  
- 工具 ≤12 个，全部走现有 REST + `trade_intel_service`  
- Client 悬浮 UI + 确认框  

### v2（+8 周）— 能收费增购

- 租户记忆、行业模板包  
- Token 单独计费项「助手包」  

### v3（+12 周）— 差异化

- 低代码工作流（对齐小傅审批流）  
- 代理壳：「帮我开户某某公司」填表草稿

## 八、风险与对策

| 风险 | 对策 |
|------|------|
| 胡说八道 | 工具调用强制走 API 真数据；生成带引用 |
| 成本失控 | 每租户日配额；模型用小模型做意图 |
| 显得花架子 | v1 只做 4 个高频意图，做透 |

## 九、给创始人一句话

**UBrain 不是再加一个菜单，而是让客户对着系统说话就能把活干了；进化的是「您家店的习惯」，不是换一套软件。**
