## 二、本轮修复（4 个产品缺陷，均已部署验证）

1. **CSRF double-submit 前端缺失** — Cookie 认证模式（token 哨兵 `'cookie'`）下所有 POST 403。修复在 `frontend/admin/src/utils/api.ts`：GET 响应头 `X-CSRF-Token` 缓存到 sessionStorage（`csrf_echo_token`），`authHeaders()` Cookie 模式回放。

4. **`views/products/edit.vue` 重复声明** — 同一 script 块两组 import 穿插语句 + `const route` 两次，Docker 构建必败（本地侥幸过）。已合并整理，`productBase` 保留。
