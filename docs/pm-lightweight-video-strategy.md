**您只管**：拍或上传 **真实的货和厂**；**看一遍** 再点发布。  
**系统不管**：替您撒谎、替您保证 Google 第一、替您乱发没看过的片。

## 一、PM 结论（对齐老板）

**同意。** 优丁阶段 A 不应把资源砸在 **自建 Cosmos/GPU 渲染农场** 上。

| 层级 | 做什么 | 不做什么 |
|------|--------|----------|
| **SaaS 内核（必做）** | 独立站、产品库、SEO/GEO 索引、honest 监测、询盘 | 自研视频大模型、保证「和实拍一模一样」 |
| **视频（编排层）** | 用 **产品图 + 老板/业务员照片 + 产品库文案** 调 **外部图生视频/数字人口播** API | 租户本地装 ffmpeg 农场、隐瞒 mock |
| **交付 honest** | 界面写清「AI 合成宣传短片，发布前请人工确认」 | 对外说「比真厂还真」、冒充实拍检测 |

珍岛学 **全链路模块**；智推学 **多模型可见性**；Google 学 **可测量**。  
我们视频学 **「两图 + 产品库 → 一条可发抖音/YouTube 的片」**，或 **「已有中文片 → 英文克隆配音出海」**，**不重造视频引擎**。

## 1.1 第二条主路径：中文视频 → 英文克隆配音（老板新提）

**非常适合大城/河间工厂**：很多厂 **抖音/视频号已有中文讲解片**，比从零 AI 生成更真、成本更低。

```text
输入
├── 租户上传中文 mp4（车间讲解、产品介绍、发货实拍带旁白）
└── 可选：产品库术语表（岩棉=A1 fire-rated rock wool… 防译错）

编排（SaaS 编排，能力调外部 API）
├── 1. 抽音频 → 语音识别 ASR（中文逐句 + 时间轴）
├── 2. 翻译 → 英文（走 glossary_terms / 建材词库，禁止乱译规格）
├── 3. 声音
│     · 方案 A：克隆原声（需租户勾选「同意声音用于出海配音」）
│     · 方案 B：选英文 TTS 男/女声（无克隆合规更简单）
├── 4. 合成：新英文音轨 + 原画面（ffmpeg 替换音轨；高级可走唇形同步 API）
├── 5. 字幕：英文字幕 srt（YouTube/TikTok/LinkedIn 必备）
└── 6. 发布：矩阵 / 独立站 VideoObject + 英文标题描述（SEO）

输出
├── en.mp4 + en.srt + 英文文案包 → 统一发布台
└── 保留 zh 原版，双语资产进租户媒体库
```

**和「两图出片」怎么选**

| 场景 | 推荐 |
|------|------|
| 厂里 **已有中文短视频** | ✅ **本路径**（翻译+配音） |
| 只有产品图、没有片 | 「两图出片」/ 图生视频 |
| 要投欧美 B2B | 英文配音 + 英文字幕 **必做** |
| 敏感规格/检测数据 | 翻译后 **人工扫一遍** 再发 |

**合规（必须写进 UI）**

- 声音克隆：**租户本人授权** 勾选，默认可用标准英文 TTS 代替  
- 界面标注：**AI 翻译配音**，非人工同传；技术参数以英文产品页为准  
- 禁止：未审片自动全平台群发

## 二、最小输入 → 最大像真片（工厂版）

```text
输入（租户 5 分钟能凑齐）
├── 产品库：品名、规格、应用、产地（大城/河间）
├── 产品图：1～3 张（已有「产品图片空间」）
├── 出镜人：老板/业务员 **全身或半身照 1 张**（可选，用于口播/走动镜头）
└── 可选：工厂外景/车间 1 张（没有则用产品图+文案生成 B-roll）

编排（SaaS 做，不渲染）
├── 从产品库生成 **30 秒口播稿**（禁止泛写「优质建材」）
├── 拆 **3～5 镜头**（介绍 / 规格 / 应用 / 工厂信任 / 询盘引导）
├── 选外部能力（按套餐/Token）：
│     · 图生视频（产品图 → 展示旋转/应用情景）
│     · 数字人/照片驱动（客户照 → 讲解）
│     · 或外链工具（Runway/Kling/豆包视频等，SaaS 只收 URL 回写）
└── 输出：mp4 + 标题/描述/标签 → **SEO 矩阵 / 统一发布台**

索引（SaaS 必做）
├── 视频页进独立站（结构化 Product + VideoObject）
├── 矩阵发布带 UTM → 询盘来源
└── GEO：产品事实与站点一致（防 AI 胡编规格）
```

**「像真的」来自**：真实规格 + 真实产品图 + 合理镜头脚本，**不是** SaaS 里藏一个假排名或 mock 色块。

## 三、和现有代码的关系（不推翻，改优先级）

| 已有 | 建议定位 |
|------|----------|
| Hermes 建站 + `product_images` 挂首屏 | ✅ **核心**，继续加强 |
| 产品库 `require_product_profile` | ✅ 视频脚本 **必须读库** |
| SEO 矩阵 / 收录 / GEO | ✅ **核心** |
| `media_factory` + Cosmos NIM | 🔽 **降级为可选实验室**；默认走 **外部 API 编排** |
| `MEDIA_FACTORY_MOCK_RENDER` | 仅 dev；生产 **必须标注 AI 合成** |
| `image_url` on render task | ✅ 已支持图生视频入口，应对接 **云 API 而非仅自建 NIM** |
| `image_to_video` 场景 ID | ✅ 产品策略默认场景 |
| TTS 页面 `/media-factory/tts` | ⚠️ **前端有、后端仅 stub**（无 synthesize / 无视频配音） |
| `glossary_terms` 全球化词库 | ✅ 翻译岩棉等术语，应接入配音流水线 |
| `media_video_edit_service` ffmpeg 剪辑 | ✅ 可复用 **换音轨/加字幕** |

**研发 Out-of-Scope（阶段 A）**：维护 GPU 集群、承诺 4K 长片、自动批量发未审片、未授权声音克隆。

## 四、对外话术（销售/代理 · 对着老板讲）

> 您 **不用会英语**，也 **不用请拍片公司**。  
>  
> **有中文视频**：手机拍的讲解、车间、装货都行 — 上传后系统帮您 **翻成英文、配上英文讲解（可像您自己的声音）**，加字幕，发到 YouTube、TikTok 找外商。  
>  
> **没有视频**：上传 **产品照片 + 您本人一张照片**，系统按您 **产品库里写的规格** 帮您做一条介绍片。  
>  
> 发之前您 **自己看一遍**，不对就改；重要参数以产品库和合同为准。

**禁忌话术**：「保证外贸询盘」「保证排名」「和央视广告一样」— 合规不允许。

## 五、PM 派工（相对 Cosmos 自建）

| ID | 事项 | 主责 | 验收 |
|----|------|------|------|
| **LV-01** | Client **「两图出片」向导**：产品图 + 人像照 → 脚本预览 | 产品+前端 | 3 步内到「待生成」 |
| **LV-02** | 渲染 **Adapter 接口**：Cosmos / Kling / 火山 / Runway **可插拔**，SaaS 只存 task+url | 后端 | 1 家云 API 跑通 |
| **LV-03** | 脚本 **强制 product_id** | 后端 | 无产品库拒绝生成 |
| **LV-04** | 发布页 **「AI 合成」标识** + 人工确认勾选 | 前端+合规 | 未勾选不能发 |
| **LV-05** | 视频页 **VideoObject + 产品链接** | SEO | 1 条 URL 收录复检 |
| **LV-06** | 下线或隐藏 **mock 色块** 对租户展示 | PM+QA | overview.mock_render 租户可见 |
| **LV-07** | **「中文片出海」向导**：上传 mp4 → 预览英译稿 → 配音 → 下载/发布 | 产品+GW-S | 1 条真实中文片跑通 |
| **LV-08** | ASR + 翻译 + TTS/克隆 **Adapter**（Azure/ElevenLabs/火山/阿里 择一） | 后端 | API 可插拔；Token 计费 |
| **LV-09** | ffmpeg **换音轨 + 烧录/外挂英文字幕** | 后端 | en.mp4 可播放 |
| **LV-10** | 声音克隆 **授权勾选** + 无克隆时降级英文 TTS | 合规+前端 | 未勾选不走克隆 |

**Cosmos 自建**：保留给 **有 GPU 的运维/Staging**，不作为大城工厂默认路径。
