## 四、每项通过标准

1. 硬刷新无白屏、无 Tab 爆闪  
2. 主按钮可点击且有反馈（message / 跳转 / 下载）  
3. 列表数据来自 API；失败显示空状态，不注入英文假模板  
4. 无 `Math.random` 刷新指标  
5. 截图归档至 `docs/送检截图/模块名.png`
