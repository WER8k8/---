# 成果保护与第三方鉴定清单

> 适用于：投资人尽调、外包验收、等保/软著配合、商业秘密说明。  
> 技术入口：**管理端 → 超级管理员 → 创始人诊断**。

---

## 一、系统已落地的保护能力

| 能力 | 说明 | 鉴定时如何演示 |
|------|------|----------------|
| 创始人微信绑死 | `FOUNDER_WECHAT_BIND_KEY=qq979072138` | 非创始人账号访问「创始人诊断」失败 |
| 国密 SM3/SM4 | `gm_crypto` + 自检接口 | 诊断页「国密自检」截图 |
| 平台级导出仅创始人 | `EXPORT_PLATFORM_FOUNDER_ONLY=true` | 普通超管导出全站 CSV 403，创始人成功 |
| 导出/访问留痕 | `operation_logs` + `security_event` | 诊断页「安全事件」列表 |
| 鉴定摘要 | `GET /founder-ops/protection-summary` | 一页统计与声明 |
| 源码不对外 | 仅部署运行包 | 说明访客无 `.py` 源码 |

---

## 二、现场演示脚本（约 15 分钟）

1. **创始人账号**登录 → 打开「创始人诊断」→ **运行诊断**、**国密自检** → 截图。  
2. 点 **鉴定摘要**、**安全事件** → 截图（含导出次数、拒绝次数）。  
3. 换 **非创始人超管**（或另一浏览器未绑微信）→ 访问创始人诊断 / 导出全站询盘 → **应 403**。  
4. 展示 **租户管理员** 仅能看本租户数据（业务隔离）。  
5. 说明：改代码在本机 Git + Cursor，服务器仅重启服务，不提供 SSH 给第三方。

## 六、对外一句话

本系统通过**创始人身份与微信绑定**、**国密算法保护敏感配置**、**全平台数据导出仅限创始人并全程留痕**等措施，降低非授权人员拷贝核心经营成果的风险；软件著作权与合同权利以登记及书面约定为准。
