## 必须拍板的 4 个问题（请会上勾选）

复制到会议纪要即可。

### 1. 酷播免费档是否满足试点 3 个月？

- [ ] **通过** — 先用酷播免费档，不够再升付费或启动 P5 七牛评估  
- [ ] **不通过** — 理由：__________ → 行动：__________

### 2. R2 是否配置自定义域名 / CDN？

- [ ] **本期不做** — 先用 R2 预签名 URL  
- [ ] **本期做** — 域名：__________ 负责人：__________

### 3. 成品保留 72 小时 + handoff 删文件，是否与对外承诺一致？

- [ ] **一致**  
- [ ] **需调整** — 改为 ______ 小时，负责人：__________

### 4. 存储策略：每个任务是否「国内酷播 + 海外 R2」双写？

- [ ] **是**（当前实现，推荐）  
- [ ] **否** — 按租户区分：国内租户仅酷播 / 海外租户仅 R2（需额外开发）
