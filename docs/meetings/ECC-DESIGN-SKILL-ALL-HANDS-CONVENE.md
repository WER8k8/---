## 为何必须全员开会

Owner 与 ECC 已确认：**现网租户后台不宜再用于融资与客户大单演示**。  
后续 UI 在 **`优丁SaaS-独立线`** 按 **Design Skill 栈 + 四屏定稿** 重建；**`上线网站`** 保留 API 与 BFF。

若 184 Agency + 38 ECC + 研发技能师 **不同步本规范**，会出现：

- 有人继续用 `ui-ux-pro-max` / `taste` 出「AI 华强北」界面  
- 有人往 `frontend/admin` 堆功能，与独立线双轨漂移  
- 营销话术与登录页不一致，客户仍判「垃圾」

**因此：本次会议为强制对齐，不是可选分享。**
