# Google Stitch 提示词模板 — 外贸B2B线索管理SaaS

## 📋 产品概述
**产品名称**：外贸B2B线索管理SaaS系统（WhatsFinds外贸获客系统）
**目标用户**：外贸业务员、销售经理、企业主
**核心功能**：线索获取、客户管理、询盘跟进、报价管理、数据分析
**设计风格**：浅色玻璃拟态 + 薄荷绿SaaS后台

## 🎨 设计规范
### 色彩方案
- **主色**：薄荷绿 (#00D4AA)
- **辅助色**：浅蓝 (#E8F4FD)、浅灰 (#F8F9FA)
- **强调色**：深蓝 (#1890FF)、橙色 (#FF6B35)
- **背景色**：白色 (#FFFFFF)、浅灰 (#F5F7FA)
- **文字色**：深灰 (#333333)、中灰 (#666666)、浅灰 (#999999)

### 玻璃拟态效果
- **背景**：半透明白色 (rgba(255,255,255,0.8))
- **模糊效果**：backdrop-filter: blur(10px)
- **边框**：1px solid rgba(255,255,255,0.3)
- **阴影**：0 8px 32px rgba(0,0,0,0.1)
- **圆角**：12px-16px

### 字体规范
- **主字体**：系统默认字体 (SF Pro, Segoe UI, Roboto)
- **中文字体**：PingFang SC, Microsoft YaHei
- **标题字号**：24px, 20px, 16px
- **正文字号**：14px, 13px
- **辅助文字**：12px

## 📱 页面清单（12个核心页面）
1. **登录页** - 统一登录入口，支持账号密码、手机验证码、微信扫码
2. **首页仪表盘** - 关键指标概览、待办事项、快速入口
3. **线索仪表盘** - 线索来源分析、转化漏斗、实时动态
4. **线索列表** - 多维度筛选、批量操作、状态标签
5. **线索详情** - 完整信息、跟进记录、关联询盘
6. **客户管理** - 客户列表、客户画像、联系人管理
7. **询盘管理** - 询盘列表、自动分配、跟进状态
8. **报价管理** - 报价模板、历史报价、利润分析
9. **数据分析** - 销售漏斗、业绩报表、趋势分析
10. **营销活动** - 邮件营销、WhatsApp营销、效果追踪
11. **系统设置** - 账号管理、权限配置、模板设置
12. **个人中心** - 个人信息、操作日志、消息通知

## 🎯 关键页面详细需求

### 1. 登录页
- **布局**：居中卡片式登录框
- **背景**：浅色渐变背景 + 玻璃拟态装饰元素
- **表单**：账号密码输入框、记住密码、忘记密码
- **第三方登录**：微信、Google、Facebook图标
- **注册入口**：底部"没有账号？立即注册"

### 2. 首页仪表盘
- **顶部导航**：Logo、搜索框、用户头像、消息通知
- **左侧菜单**：可折叠侧边栏，玻璃拟态效果
- **数据卡片**：今日新增线索、待跟进客户、本月业绩、转化率
- **图表区域**：线索来源饼图、趋势折线图、漏斗图
- **待办列表**：今日待办、即将到期任务
- **快速入口**：新建线索、导入客户、发送报价

### 3. 线索仪表盘
- **数据概览**：总线索数、今日新增、本周转化、本月业绩
- **来源分析**：Google、Facebook、LinkedIn、展会、推荐
- **转化漏斗**：线索→询盘→报价→成交
- **实时动态**：最新线索、最新询盘、最新成交
- **地图分布**：全球客户分布热力图

### 4. 线索列表
- **筛选条件**：来源、状态、时间、负责人、标签
- **列表视图**：表格形式，支持排序、分页
- **卡片视图**：卡片形式，支持拖拽排序
- **批量操作**：分配、导出、删除、标签
- **状态标签**：新线索、跟进中、已转化、已失效

### 5. 线索详情
- **基本信息**：姓名、公司、邮箱、电话、来源
- **跟进记录**：时间线形式，支持添加备注
- **关联询盘**：关联的询盘列表
- **操作按钮**：编辑、分配、发送邮件、添加标签
- **相似线索**：系统推荐的相似线索

### 6. 客户管理
- **客户列表**：公司名称、联系人、行业、规模、状态
- **客户画像**：客户标签、交易历史、沟通记录
- **联系人管理**：多个联系人、主要联系人标记
- **客户分组**：按行业、规模、地区分组
- **导入导出**：Excel导入、数据导出

### 7. 询盘管理
- **询盘列表**：询盘内容、客户信息、分配状态
- **自动分配**：按规则自动分配给业务员
- **跟进状态**：待处理、跟进中、已报价、已成交
- **回复模板**：预设回复模板、多语言支持
- **询盘分析**：询盘来源、转化率分析

### 8. 报价管理
- **报价模板**：可定制报价单模板
- **报价历史**：历史报价记录、状态跟踪
- **利润分析**：成本、利润、毛利率计算
- **报价审批**：多级审批流程
- **PDF导出**：生成PDF报价单

### 9. 数据分析
- **销售漏斗**：线索→询盘→报价→成交漏斗
- **业绩报表**：个人业绩、团队业绩、趋势分析
- **客户分析**：客户分布、行业分析、规模分析
- **产品分析**：热门产品、利润分析、库存分析
- **自定义报表**：拖拽式报表设计器

### 10. 营销活动
- **邮件营销**：模板设计、批量发送、效果追踪
- **WhatsApp营销**：消息模板、批量发送、已读回执
- **活动管理**：活动创建、参与人员、效果分析
- **客户分群**：按条件筛选目标客户
- **A/B测试**：多版本测试、效果对比

### 11. 系统设置
- **账号管理**：用户列表、角色权限、部门管理
- **权限配置**：菜单权限、数据权限、操作权限
- **模板设置**：邮件模板、报价模板、合同模板
- **集成设置**：第三方服务集成、API配置
- **系统日志**：操作日志、登录日志、异常日志

### 12. 个人中心
- **个人信息**：头像、姓名、联系方式、职位
- **修改密码**：密码修改、二次验证
- **操作日志**：个人操作记录
- **消息通知**：系统通知、待办提醒
- **偏好设置**：语言、时区、主题设置

## 🛠️ 技术实现要求
### 前端技术栈
- **框架**：Vue 3 + TypeScript
- **UI库**：Ant Design Vue 4.x
- **状态管理**：Pinia
- **图表**：ECharts 5.x
- **国际化**：vue-i18n
- **样式**：Tailwind CSS + 自定义玻璃拟态样式

### 响应式设计
- **桌面端**：1200px+ 三栏布局
- **平板端**：768px-1199px 两栏布局
- **移动端**：<768px 单栏布局

### 多语言支持
- **默认语言**：中文
- **支持语言**：英语、西班牙语、阿拉伯语、俄语
- **RTL支持**：阿拉伯语从右到左布局
