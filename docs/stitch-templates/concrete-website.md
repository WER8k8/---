# Google Stitch 提示词模板 — 轻集料混凝土官网

## 📋 产品概述
**产品名称**：轻集料混凝土官网 — 企业级全栈AI SEO系统
**目标用户**：建筑公司、装修公司、设计师、工程采购
**核心功能**：产品展示、技术资料、案例展示、在线咨询、SEO优化
**设计风格**：专业简洁 + 科技感 + 行业蓝

## 🎨 设计规范
### 色彩方案
- **主色**：行业蓝 (#1890FF)
- **辅助色**：科技蓝 (#096DD9)、浅蓝 (#E6F7FF)
- **强调色**：活力橙 (#FF6B35)、成功绿 (#52C41A)
- **背景色**：白色 (#FFFFFF)、浅灰 (#F5F7FA)
- **文字色**：深灰 (#333333)、中灰 (#666666)、浅灰 (#999999)

### 设计风格
- **专业简洁**：清晰的层次结构，突出产品信息
- **科技感**：渐变背景、微动效、数据可视化
- **行业蓝**：体现建筑行业的专业性和可靠性

### 字体规范
- **主字体**：系统默认字体 (SF Pro, Segoe UI, Roboto)
- **中文字体**：PingFang SC, Microsoft YaHei
- **标题字号**：32px, 24px, 20px
- **正文字号**：16px, 14px
- **辅助文字**：12px

## 📱 页面清单（8个核心页面）
1. **首页** - 产品概览、核心优势、案例展示、新闻动态
2. **产品中心** - 产品分类、产品详情、技术参数、应用领域
3. **技术资料** - 技术文档、施工指南、检测报告、下载中心
4. **工程案例** - 案例展示、案例详情、客户评价、项目数据
5. **关于我们** - 公司介绍、发展历程、荣誉资质、团队风采
6. **新闻动态** - 公司新闻、行业资讯、技术文章、活动公告
7. **联系我们** - 联系方式、在线咨询、地图定位、留言反馈
8. **SEO优化页** - 长尾关键词页面、产品对比、FAQ

## 🎯 关键页面详细需求

### 1. 首页
- **顶部导航**：Logo、主导航、语言切换、搜索框、联系方式
- **轮播横幅**：3-5张高质量Banner，展示核心产品和应用
- **产品概览**：3-4个核心产品卡片，突出优势和应用场景
- **核心优势**：4-6个优势图标卡片，突出技术、质量、服务
- **案例展示**：3-4个精选案例，带图片和简短描述
- **新闻动态**：3-4篇最新新闻，带标题和发布时间
- **数据统计**：项目数量、客户数量、服务年限、满意度
- **合作伙伴**：合作伙伴Logo滚动展示
- **底部信息**：联系方式、快速链接、版权信息、备案号

### 2. 产品中心
- **产品分类**：左侧分类导航，支持多级分类
- **产品列表**：网格/列表视图切换，筛选排序
- **产品卡片**：产品图片、名称、简短描述、查看详情按钮
- **产品详情**：
  - 产品图片轮播
  - 产品名称、型号、价格
  - 技术参数表格
  - 应用领域说明
  - 相关产品推荐
  - 下载资料（PDF、CAD）
  - 在线咨询按钮

### 3. 技术资料
- **资料分类**：技术文档、施工指南、检测报告、认证证书
- **资料列表**：标题、文件类型、大小、下载次数
- **在线预览**：PDF在线预览功能
- **下载中心**：批量下载、收藏功能
- **搜索功能**：按关键词搜索资料

### 4. 工程案例
- **案例筛选**：按地区、类型、规模筛选
- **案例列表**：案例图片、项目名称、地点、规模
- **案例详情**：
  - 项目基本信息
  - 施工过程图片
  - 完工效果展示
  - 客户评价
  - 技术难点及解决方案
  - 相关产品链接

### 5. 关于我们
- **公司介绍**：公司概况、企业文化、发展愿景
- **发展历程**：时间轴形式展示公司发展历程
- **荣誉资质**：证书图片、荣誉墙
- **团队风采**：团队介绍、员工活动
- **工厂实拍**：工厂环境、生产设备、质量控制

### 6. 新闻动态
- **新闻分类**：公司新闻、行业资讯、技术文章
- **新闻列表**：标题、摘要、发布时间、阅读量
- **新闻详情**：
  - 完整文章内容
  - 相关新闻推荐
  - 分享功能
  - 评论功能（可选）

### 7. 联系我们
- **联系方式**：电话、邮箱、地址、工作时间
- **在线咨询**：在线客服、微信二维码
- **地图定位**：百度地图/高德地图集成
- **留言反馈**：表单提交，支持文件上传
- **分支机构**：各地分支机构联系方式

### 8. SEO优化页
- **长尾关键词页**：针对特定关键词的优化页面
- **产品对比页**：不同产品对比分析
- **FAQ页面**：常见问题解答
- **百科知识**：轻集料混凝土相关知识

## 📝 使用说明
1. 将此提示词复制到Google Stitch中
2. 根据实际产品线调整产品分类和详情
3. 生成设计后，导出HTML和Vue组件
4. 使用Codex读取设计文件，自动生成Nuxt.js项目代码
5. 对接后端API，集成SEO优化功能
6. 部署上线，持续监控SEO效果

## 🔍 SEO优化要点
### 技术SEO
- **SSR渲染**：确保搜索引擎可抓取
- **URL结构**：语义化URL，包含关键词
- **Meta标签**：动态生成Title、Description、Keywords
- **结构化数据**：JSON-LD标记产品、文章、公司信息
- **站点地图**：自动生成XML站点地图
- **Robots.txt**：合理配置抓取规则

### 内容SEO
- **关键词策略**：核心关键词、长尾关键词布局
- **内容质量**：高质量原创内容，定期更新
- **内部链接**：合理的内部链接结构
- **图片优化**：Alt标签、文件名优化
- **页面速度**：Core Web Vitals优化

### 本地SEO
- **百度地图**：百度地图标注
- **企业信息**：百度企业号、微信公众号
- **本地关键词**：地区+产品关键词优化
