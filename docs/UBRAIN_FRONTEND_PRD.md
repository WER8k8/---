## 2. 产品定义

### 2.1 Product Goals（产品目标）

1. **提供直观的对话式AI助手界面**：打造类似豆包的对话交互体验，让用户通过自然语言指令高效完成复杂任务，降低操作门槛
2. **突出AccioWork核心电商能力**：重点展示自动谈单、智能找客户、AI写开发信三大核心功能，帮助建材行业客户快速实现销售自动化
3. **建立客户裂变增长机制**：设计客户盈利后的邀请推荐体系，通过推荐码、佣金激励等方式形成网络效应，实现用户自增长

### 2.2 User Stories（用户故事）

1. **作为建材外贸业务员**，我想要通过对话界面让AI自动分析客户需求并生成个性化开发信，以便我能高效触达潜在客户
2. **作为外贸企业主**，我想要平台自动寻找匹配的海外买家并建立联系，以便我能扩大客户群体并提高成交率
3. **作为已盈利客户**，我想要通过推荐码邀请同行使用平台并获得佣金奖励，以便我能从平台增长中获益
4. **作为新用户**，我想要直观地看到AccioWork的8个技能包（特别是自动谈单、找客户、写开发信）并快速上手使用
5. **作为平台运营者**，我想要监控客户使用数据和盈利情况，以便优化推荐机制和产品功能

## 3. 技术规范

### 3.1 Requirements Pool（需求池）

#### P0（必须有）
- **对话式交互界面**：左侧对话列表，右侧对话窗口，支持多轮对话历史
- **AccioWork技能包集成**：展示并调用8个电商技能包，重点突出：
  - 智能选品
  - 以图搜品
  - 一键建站
  - SEO优化
  - 广告生成
  - 社媒日历
  - 供应商匹配
  - 合规检查
- **核心功能调用**：
  - 自动谈单：AI与客户邮件/在线聊天自动沟通
  - 智能找客户：基于产品特性和市场数据自动寻找潜在客户
  - 开发信生成：根据客户画像自动生成个性化开发信
- **实时通信**：WebSocket支持对话实时响应和任务状态更新
- **用户认证**：登录/注册，权限控制

#### P1（应该有）
- **多轮对话记忆**：记住用户偏好和上下文，实现"越用越聪明"
- **任务进度可视化**：展示研究/执行任务的实时进度
- **结果展示组件**：研究报告、客户列表、开发信预览等富文本展示
- **基础数据分析**：使用统计、任务完成情况等简单报表
- **移动端适配**：响应式设计，支持手机和平板访问

#### P2（可以有）
- **客户邀请系统**：推荐码生成、佣金统计、邀请链接分享
- **高级分析仪表板**：转化率、ROI、客户生命周期等深度分析
- **多语言支持**：界面和内容支持英文、西班牙语等目标市场语言
- **主题切换**：深色/浅色模式，用户自定义主题色

### 3.2 UI Design Draft（UI设计稿描述）

#### 整体布局
采用类似豆包的三栏布局：

```
┌─────────────────────────────────────────────────────────┐
│ 顶部导航栏：Logo、搜索框、用户头像、设置                     │
├───────────┬─────────────────────────────────────────────┤
│           │                                             │
│ 左侧栏    │              主对话区域                       │
│ 300px     │                                             │
│           │  ┌─────────────────────────────────────┐    │
│ 对话列表  │  │ 消息区域                              │    │
│ + 按钮    │  │ - 用户消息（右对齐）                  │    │
│           │  │ - AI消息（左对齐）                    │    │
│ 历史记录  │  │ - 技能包卡片                         │    │
│ 分组      │  │ - 任务进度组件                       │    │
│           │  └─────────────────────────────────────┘    │
│           │                                             │
│           │  ┌─────────────────────────────────────┐    │
│           │  │ 输入区域                              │    │
│           │  │ - 文本输入框                          │    │
│           │  │ - 技能包快捷按钮                      │    │
│           │  │ - 发送按钮                            │    │
│           │  └─────────────────────────────────────┘    │
└───────────┴─────────────────────────────────────────────┘
```

#### 核心功能区域
1. **技能包展示**：在对话窗口上方或侧边栏展示AccioWork的8个技能包图标，点击可快速发起相关任务
2. **对话消息类型**：
   - 文本消息：普通对话内容
   - 技能包卡片：展示技能包功能和快速操作按钮
   - 任务进度条：显示长时间任务的执行进度
   - 结果卡片：展示研究报告、客户列表、开发信预览等
3. **客户邀请模块**：在个人中心或侧边栏添加邀请入口，展示推荐码和佣金统计

#### 关键交互流程
1. **自动谈单流程**：用户输入"帮我找美国建材买家" → AI展示搜索进度 → 返回客户列表 → 用户选择客户 → AI生成开发信草稿 → 用户确认发送
2. **客户邀请流程**：用户点击"邀请好友" → 生成专属推荐码 → 分享给好友 → 好友注册并使用 → 双方获得奖励
