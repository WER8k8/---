## 能讲什么（可对外承诺）

1. **独立站 + 多平台发布**：内容可生成、可排队发布；成功须有平台链接或任务 ID（不宣称「已收录」除非有探测证据）。
2. **询盘进系统**：租户站表单 / IM 条留言进统一 inbox；**手机或邮箱必填**；销售企微推送需客户自配密钥。
3. **站点体检**：真抓 URL 查 Meta、结构、移动适配——分数可照着改站，**不保证**百度前三。
4. **GEO 引擎（配 Key 后）**：真调大模型问「是否提及品牌」——看「已提及 / 未提及 / 未接通」，**不是** ChatGPT 网页排名榜。
5. **SEO 矩阵**：关键词生成、内容、发布任务、收录探测（生产环境 `site:` 探测；dev 为 stub 跳过）。

---

## 不能讲什么（禁止夸大）

| 禁止说法 | 原因 |
|----------|------|
| 「保证 AI 搜索排名第一」 | GEO 分仅为模型提及探测，非榜单 |
| 「关键词排名已上首页」 | 排名追踪易模拟/反爬；须看 `is_simulated` |
| 「百度站长数据已对接」 | 无 `site_token` 时页面为演示数 |
| 「GEO 基因分析提升卖货」 | `/admin/geo` 为 NCBI 生物库，与建材无关 |
| 「抖音已自动谈单成交」 | 5c 须 Worker + 生产 Key；无则 503 |
| 「实验室功能已商用」 | 默认 `admin_lab_enabled=0`，须套餐或评审 Kill |

---

## 30 秒自检（见客户前）

1. GEO 卡片是否「监测未接通」？→ 别提分数。  
2. 百度站长是否绑 token？→ 别提索引量。  
3. 收录是否在 dev 环境？→ 别提「已收录」。  
4. **最终效果**以 **真实询盘电话 + 站长后台 + 独立域收录** 为准。
