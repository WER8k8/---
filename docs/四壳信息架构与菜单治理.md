# 四壳信息架构与菜单治理（2026 执行版）

> 配套：`docs/战略总纲-2026-面向融资与政府.md`  
> **目标**：专业人员 3 分钟内看懂结构；租户 3 次点击内完成主任务  

---

## 一、四套壳（必须物理分离路由）

| 壳 ID | 路径前缀 | 登录角色 | 首页回答的问题 |
|-------|----------|----------|----------------|
| **Client** | `/client/*` | 租户老板/运营 | 我今天该干什么？ |
| **Ops** | `/dashboard` 等业务区 | 内部运营、大租户编辑 | 内容与线索怎么管？ |
| **Platform** | `/admin/*` 治理区 | super_admin / admin | 平台稳不稳、钱对不对？ |
| **Agent** | `/agent/*`（新建） | l2 / l3 | 我能赚多少、待开户谁？ |

**访客站**（Nuxt）不算壳，但须在 Client 工作台链回「查看我的网站」。

---

## 二、租户 Client — 四支柱（菜单最多 4+1）

| 支柱 | 合并原能力 | 主操作 |
|------|------------|--------|
| **获客** | 询盘 unified、IM 配置、国际询盘入口 | 未读列表 → 一键回复 / 转 IM |
| **发品** | 产品、内容、统一发布枢纽 | 选母版 → 选平台 → 看进度 |
| **履约** | 订单、物流运单 | 填单号 → 看轨迹 |
| **账户** | 套餐、域名、设置、邀请 | 续费、绑域、配额 |

**+1**：右下角 **「优丁助手」**（UBrain 副驾，非菜单项）

### Onboarding 向导（首次登录强制或强引导）

```
步骤1 套餐生效 → 步骤2 绑独立域 → 步骤3 选发布母版
→ 步骤4 勾选平台(先5+5) → 步骤5 开IM → 步骤6 发第一条
```

未完成步骤在 Dashboard 以 **一条卡片** 展示，不堆列表。

## 三、超管 Platform — 三区 Tab

### Tab A · 运营

- 租户总览、套餐、发布任务队列、询盘大盘、告警  

### Tab B · 商业

- 营收、成本、分润、对账导出、发票（P1-08）  

### Tab C · 治理

- 域名/SSL、运维 cron、AI 配置、审计日志、备份  

### 实验室（默认关闭 Feature Flag）

GEO 基因、RAG、认知、边缘 CDN、媒体工厂、养号、v2ray-legacy…

**入口**：治理区 → 「实验室」抽屉，需二次确认。

## 五、现有菜单治理原则（对照 `layout/index.vue`）

### 保留在主路径

- 总览、产品/内容、询盘、SEO 核心、发布枢纽、租户 SaaS、财务、运维  

### 合并

| 现入口 | 并入 |
|--------|------|
| ai-center / ai-engine / ai-config | Platform·治理 → AI 配置（单页 Tab） |
| inquiries + international/inquiries | Client·获客 |
| 多个 SEO 子页 | Ops·SEO 中心（二级 Tab） |

### 进实验室

- cognitive、edge-cdn、media-factory、developer、agent-hub（保留 API，UI 降级）  

### 待下架或仅内网

- code-tools、file-manager 演示壳（P2-03）  
- capability-hub 本地 storage 叙事 → 改为真实 API 或删除对外链接

## 六、路由迁移策略（不 Big Bang）

1. **新建 Layout**：`layouts/ClientShell.vue`、`PlatformShell.vue`、`AgentShell.vue`  
2. **旧路由 redirect** 301 到新路径（保留书签）  
3. **每周下线 ≤5 个顶层菜单**，同步更新进度看板  
4. **E2E**：每壳 1 条冒烟（登录 → 主操作 → 退出）

## 七、2026 视觉（不换 UI 库）

使用 `frontend/admin/src/styles/design-tokens.scss`：

- 主色单一（品牌蓝）、背景浅灰、卡片大圆角  
- 表格默认 **中等密度**；空状态统一插画+一句人话  
- 登录页、租户 Dashboard **单独设计**，对标飞书/现代 SaaS 克制风
