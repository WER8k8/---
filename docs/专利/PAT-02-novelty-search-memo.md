## 1. 本申请技术方案摘要

**名称（拟）**：基于多智能体协同与 BFF 菜单治理的建材外贸 AI-SaaS 营销平台方法及系统。

**核心区别特征**（相对通用 CRM/SaaS）：

1. **Admin BFF 菜单绞杀者**：按租户/套餐/角色下发 Client/Agent/Platform 三壳菜单，非静态前端路由表。
2. **UBrain 动作审计链**：AI 推荐动作与人工确认写入可审计队列（flywheel 028）。
3. **Plan Gate + Stub 矩阵**：未完成激活的 SaaS 能力对租户不可见，非简单 feature flag。
4. **询盘统一列表**：SEO 线索与 B2B 询盘列合并为 `/inquiries/unified` 工作队列范式。
