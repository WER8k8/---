# 出海参谋 — 贸易情报 × 建材品类 × UBrain（产品补充）

> **角色视角**：产品经理 · 运营主管 · 营销主管  
> **关联**：`docs/UBrain-统一调度大脑-产品规格.md`、`docs/战略总纲-2026-面向融资与政府.md`  
> **一句话**：像「生意参谋」帮淘宝店主看款一样，帮建材老板看 **能不能出口、往哪出口、值不值得做** —— **先问优丁助手，少问人**。

---

## 一、为什么必须做（三方共识）

| 角色 | 痛点 | 出海参谋的价值 |
|------|------|----------------|
| **产品经理** | 建材 SKU 极多（规格、标准、用途交叉），出海规则复杂 | 把「品类 × 国家 × 合规」结构化，变成可计算能力 |
| **运营主管** | 销售/客服被问爆：「这个能做出口吗？」「沙特要不要证？」 | **80% 重复问答** 交给 UBrain + 情报库，人只处理例外 |
| **营销主管** | 卖点难讲清，客户觉得「就是个发帖工具」 | 对外：**蓝海市场雷达 + 出口可行性秒答** = 差异化主叙事 |

**结论**：这不是「再加一个报表」，而是 **UBrain 的行业大脑**；没有它，助手只是通用 ChatGPT；有了它，才是 **建材外贸 OS**。

## 二、和「海关数据 / 生意参谋」的关系（务实说法）

### 2.1 能对齐什么

| 能力 | 生意参谋（淘宝系） | 我们「出海参谋」 |
|------|------------------|------------------|
| 看需求趋势 | 搜索热度、成交趋势 | **目的国 × 品类** 进口增速、询盘热度（多源） |
| 看竞争 | 同行密度 | 40 平台同类发布量、关键词难度（已有 SEO 能力延伸） |
| 看能不能做 | 类目准入 | **HS 编码 + 出口管制 + 认证清单 + 反倾销提示** |
| 看往哪做 | 人群/地域 | **蓝海评分**：增速高、竞争相对低、与租户产品匹配 |

### 2.2 数据从哪来（分三层，避免吹牛）

| 层级 | 来源 | 成本 | 阶段 |
|------|------|------|------|
| **L1 规则与知识库** | 建材 Wiki、国标/欧标摘要、PM 维护「国家-品类-证照」表 | 低 | **MVP（0～3 月）** |
| **L2 官方统计** | 海关总署 **公开统计**（章别进口额、国别），非实时逐票 | 低～中 | **v1.5** |
| **L3 商业数据** | 特易、外贸邦、海关数据服务商 API（需签约） | 高 | **v2**（有收入再做） |

**不对客户承诺**：「和淘宝生意参谋一样实时到每一笔」——除非已采购 L3。  
**对客户承诺**：「基于海关分类与规则引擎 + 可升级真实贸易数据，**结论可解释、可溯源**」。

### 2.3 HS 编码（建材超多品类的抓手）

- 租户录入产品时：**AI 建议 HS 章/目**（人工确认）  
- 助手回答时：**必须带 HS 与依据**（「属于第 68 章 …，需关注 … 认证」）  
- 复用：`building-wiki`、产品规格表、后续 `trade_hs_mapping` 表

## 三、UBrain 里怎么问（用户侧）

### 典型对话（营销可直接当 Slogan）

```
老板：轻集料混凝土 B 型能出口沙特吗？
助手：可以谨慎做。HS 6810… 需符合 SASO 相关建材要求；
      近12月海湾进口增速 +8%，竞争中等；
      建议先小批量 + 询盘测试。 [查看证照清单] [生成一页出海说明]

老板：我做保温板，哪里是蓝海？
助手：根据您的品类与产能，推荐优先：越南、印尼、波兰（增速高、竞品发布量较低）；
      美国市场量大但认证成本高。 [一键加入发布计划]
```

### 意图清单（研发可验收）

| 意图 ID | 用户说法 | 输出 |
|---------|----------|------|
| `export_feasibility` | 能做出口吗 / 能不能发到 xx 国 | 能/慎/难 + 原因 + 证照 |
| `blue_ocean` | 蓝海 / 哪个国家好卖 | Top3 国 + 简短理由 |
| `hs_lookup` | 海关编码 / HS | 编码 + 章注说明 |
| `cert_list` | 要什么证 | CE、ASTM、SASO 等清单 |
| `risk_alert` | 反倾销 / 管制 | 公开信息提示 + 免责声明 |

**所有回答页脚**：「仅供参考，不构成法律意见；签约前请专业报关/律师确认。」

## 四、产品在界面放哪（不增加菜单海洋）

推荐：**不单独做第十个菜单**，而是：

1. **Client · 获客/发品** 卡片：「今日蓝海建议 1 条」  
2. **产品编辑页** 侧栏：「出口可行性 · 已评估」  
3. **UBrain** 承接全部深度问答（主入口）  
4. **超管 · 商业区** 看板：全行业热度（脱敏聚合，用于运营选品活动）  

营销对外名：**「出海参谋」**（模块）+ **「优丁助手」**（入口）。

## 七、运营 & 营销打法

### 运营

- 每周 PM 更新 **矩阵**（新政策、双反案件）  
- 客服话术：**「先问助手，截图解决不了再拉群」**  
- 把高频问题沉淀为 **模板**（UBrain L1 记忆）  

### 营销

- 主 KV：**「别猜能不能出海，问一句就有数」**  
- 案例：某厂按助手建议切越南，询盘 +X%（需真实试点）  
- 与 **七步闭环** 绑定：可行性 → 再绑域发布，减少无效开通  

### 政府/补贴

- 强调：**外贸大数据辅助决策、中小企业数字化出海**，符合常见专项表述（以当地指南为准）。

## 八、风险与边界

| 风险 | 控制 |
|------|------|
| 数据不准被告 | 免责声明 + 来源标注 + 人工矩阵复核 |
| 侵权生意参谋 | 自称「出海参谋」，不抄 UI、不宣称官方合作 |
| 成本失控 | L3 数据仅旗舰套餐；L1 规则全量开放 |
| 品类爆炸 | 先 **20 大类 × 50 国**，再细 SKU |

## 九、三方签字级结论

| 角色 | 结论 |
|------|------|
| **产品经理** | ✅ 纳入战略总纲 **P4+**，与 UBrain v1 并行；MVP 用规则矩阵，不堵在买数据上 |
| **运营主管** | ✅ 作为客服降本核心；考核「助手解决率」 |
| **营销主管** | ✅ 作为主卖点 #2（#1 仍是七步卖货 OS） |

**给创始人的话**：您不必自己懂海关 —— 团队维护一张「国家×品类」表，客户只跟 **超级调度师** 说话；专业人员看到的是 **有依据、能溯源** 的系统，不是聊天玩具。
