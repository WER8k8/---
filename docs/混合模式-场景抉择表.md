# 混合模式 · 场景抉择表（UJ 建材卖货 OS）

> 执行规则：`.cursor/rules/04-hybrid-mode-scenarios.mdc`、`.lingma/rules/hybrid-mode-scenarios.md`

## 模式定义

| 模式 | 编排 | 智能体规模 | MCP |
|------|------|------------|-----|
| **M0** 即答 | 无 | 0 | 无 |
| **M1** 单兵 | L1+L4 | 1 | 0～2 |
| **M2** 单栈 | L1～L4 | 1 主 + ECC | 2～3 |
| **M3** 蜂群 | 拆包并行+合并 | 指挥+多包 | 按包 |
| **M4** 全链 | Agency 7 阶段 | 按阶段 | 按阶段 |

## 组合示例

| 用户说法 | 判定 | 执行 |
|----------|------|------|
| 「修登录 500」 | S08 M1 | 单兵 backend + pytest |
| 「加 egress 加购页」 | S05 M3 | 契约→backend∥admin→合并 |
| 「准备上线演示」 | S13 M4 | 7 阶段+演示脚本 |
| 「询盘列表又乱了」 | S02 M2 或 S15 | 若 v1/v2 混杂则 M2 unified；多文件则 M3 |
| 「SSL 真证书」 | S11 M2 | ACME webhook，不 mock |

## 禁止

| 禁止 | 应用模式 |
|------|----------|
| 小改用 M4 全流程 | 用 M1/M2 |
| 可并行却一人串行拖很久 | 用 M3 |
| 多 agent 改 `routes/__init__.py` | 指挥单点合并 |
| 未选主栈就混写 Node+Py 新业务 | S10：FastAPI 优先 |
