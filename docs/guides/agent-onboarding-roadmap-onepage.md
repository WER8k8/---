# 代理开户后 · 客户怎么走（一页纸 · 可转发）

> **给代理/客服**：客户开户成功后，把下面文字或链接发给客户即可。  
> 客户入口：登录后台 → **开通向导**

---

## 发给客户的话（复制即用）

恭喜开户成功！按下面 **5 步** 做，就能接单：

**① 把店开起来（约 2 分钟）**  
进「开通向导」，填您卖啥（如岩棉板），点 **一键开业**，系统自动做官网。

**② 让人看见您**  
绑抖音 → 发一条视频 → 上架一个产品。

**③ 客户找得到您**  
在官网留好电话微信；在「IM 全渠道」接好留言（别漏消息）。

**④ 销售收得到消息（最重要，别漏）**  
在「IM 全渠道」里配 **企微销售推送**，填您公司企微和销售是谁。  
详细图文：见《企微 5 分钟配置说明》。

**⑤ 天天接单**  
工作台看询盘、回客户、继续发视频。  
网址绑定可以稍后再弄。
