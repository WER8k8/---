## 2. 逐步操作说明

### 2.1 登录认证（`/login`）

1. 打开 Admin 根地址，应跳转登录页。  
2. 输入账号密码 → **登录**。  
3. **通过标准**：进入主布局，左侧菜单可见，无白屏/无限 loading。  
4. **解说词**：「平台采用 JWT 会话，支持角色权限与 401 静默刷新。」

### 2.2 数据概览（`/dashboard`）

1. 登录后进入 `/dashboard`（或菜单「数据概览」）。  
2. 等待卡片/图表加载完成。  
3. **通过标准**：指标来自 API 或合规空状态；无 `Math.random` 跳动数字。  
4. **解说词**：「工作台聚合业务 KPI，数据来自后端 REST API。」

### 2.3 产品管理（`/products`）

1. 菜单 → 产品管理 → 列表。  
2. 点击一条记录进入编辑或打开新建（若有）。  
3. **通过标准**：列表可分页/搜索；保存有 message 反馈。  

### 2.4 分类管理（`/products/categories`）

1. 打开分类树页面。  
2. 展开节点，演示树形结构。  
3. **通过标准**：树来自 `/api/v1/products/categories` 或等价接口。

### 2.5 客户开发（`/sales/customer-finder`）

1. 销售中心 → 客户开发。  
2. 输入关键词触发搜索。  
3. **通过标准**：请求 `/api/v1/sales` 相关接口；失败显示空状态而非假英文模板。

### 2.6 开发信（`/sales/email-automation`）

1. 打开开发信/邮件自动化列表。  
2. 展示活动列表或创建入口。  
3. **通过标准**：主按钮可点且有反馈。

### 2.7 海外询盘（`/international/inquiries`）

1. 国际订单采集 → 海外询盘。  
2. 展示询盘列表，可选一条查看详情。  
3. **通过标准**：数据来自 `/api/v1/inquiries` 或 unified 接口。

### 2.8 SEO 发布（`/seo-matrix/publish`）

1. SEO 矩阵 → 发布。  
2. 展示发布队列或单条发布表单。  
3. **通过标准**：与 `/api/v1/seo-matrix` 交互或合规空态。

### 2.9 租户注册（`/tenants/register`）

1. **新标签页**打开 `/tenants/register`（公开页，无需登录）。  
2. 填写必填项（可不提交，或提交测试租户）。  
3. **通过标准**：表单校验中文提示；提交调用 `/api/v1/tenants`。

### 2.10 AI 内容（`/admin/ai-center/content`）

1. 超级管理员 → AI 中心 → AI 内容助手。  
2. 输入短文本，点击优化/生成（若 G4 Key 未配，展示配置引导或空态）。  
3. **通过标准**：无前端随机进度条；须声明 staging 是否配置真实 AI Key。

### 2.11 系统健康（`/system-health/dashboard`）

1. 系统健康 → 仪表盘。  
2. 展示 CPU/服务状态或监控卡片。  
3. **通过标准**：页面无崩溃；指标来自 health/monitor API。

### 2.12 出海参谋（`/admin/ai-engine/trade-intel`）

1. AI 引擎 → 出海参谋。  
2. 展示贸易情报列表或「种子同步」操作。  
3. **通过标准**：调用 `/api/v1/trade-intel`；同步按钮有 loading/结果提示。
