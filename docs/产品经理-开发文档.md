## 二、产品定义（PRD 摘要）

### 2.1 一句话

**建材 AI 卖货 OS**：租户拥有 **独立官网（www.xxxx.com）**，用 AI（**Token**）写好 **一篇母版**，经 **SEO + GEO** 分发 **国内约 20 + 国外约 20** 平台；流量在租户站完成 **询盘 → 订单 → 物流**；用 **优丁助手（UBrain）** 一句话办事（含 **能不能出口、蓝海市场**）。收入：**SaaS + Token + 静态 IP/指纹**。

**对外第二卖点**：**出海参谋** —— 建材版「出海生意参谋」，数据可溯源，不承诺与淘宝生意参谋实时同源。

**对外第三入口**：**出海计 App**（租户手机必装）—— 打开即 **优丁助手**，像豆包一样说话就能卖货、问能不能出口；平台母品牌仍为 **优丁建材 AI 卖货 OS**。

### 2.2 不做什么（范围外）

- 不给租户提供 **自助 v2ray / 翻墙** 产品模块  
- 不把 CDN、认知智能、多媒体工厂等作为 **MVP 主叙事**（可保留实验室入口）  
- **海外养号周期** 不作为首版必做（P3 增值包）

### 2.3 租户七步闭环（验收故事线）

```text
① 开通 SaaS、选套餐
② 绑定独立域名（www.xxxx.com）
③ 维护产品与案例
④ 统一发布台：创建「一篇母版」content_master
⑤ 一键 SEO+GEO，生成多平台任务并分发（国内/海外执行面）
⑥ 租户站收询盘、报价、下单
⑦ 客户在租户站查物流轨迹
```

演示验收：**走完 ①→④→⑥→⑦ 即算 MVP 演示通过**；⑤ 可先 **5+5 平台试点**。

### 2.4 公司侧两条增长线

| 线路 | 对象 | 机制 |
|------|------|------|
| **卖货线** | 终端采购商 | 40 平台 → 租户独立域 → 询盘/订单 |
| **拉租户线** | 工厂老板 | **呼朋唤友**：L1/L3/L5 + 季度榜 |

### 2.5 2026 产品架构（四壳 · 不整库迁移）

> 详规：`docs/四壳信息架构与菜单治理.md` · 决策：`docs/战略总纲-2026-面向融资与政府.md`

| 壳 | 路径 | 用户 | 一级能力上限 |
|----|------|------|----------------|
| **Client** | `/client/*` | 租户 | **4 支柱**：获客 / 发品 / 履约 / 账户 |
| **Ops** | `/dashboard` 等业务区 | 运营、大租户编辑 | 内容、SEO、发布、线索 |
| **Platform** | `/admin/*` 治理区 | super_admin | **三区**：运营 / 商业 / 治理 |

### 2.6 UBrain — 统一调度大脑（优丁助手）

> 详规：`docs/UBrain-统一调度大脑-产品规格.md`

| 项 | 说明 |
|----|------|
| **定位** | 全站 **唯一** AI 入口；用户说话 → 调现有 API → 可确认后执行 |
| **入口** | **出海计 App 首页**；Web Client 悬浮钮；Ops 顶栏 |
| **v1 意图** | 查/草拟询盘、查发布状态、查 SSL、**出口可行性**、**蓝海 Top3** |
| **进化** | L1 租户偏好（平台勾选、语气）；**禁止**跨租户训练；L2/L3 需单独开通 |
| **API（规划）** | `POST /api/v1/ubrain/chat`；工具层 `backend/app/services/ubrain/` |

### 2.7 出海参谋 — 贸易情报（建材品类 × 海关）

> 详规：`docs/出海参谋-贸易情报与UBrain.md`

| 阶段 | 能力 | 数据层 |
|------|------|--------|
| **M0** | 「能做出口吗」秒答 + HS 建议 + 证照清单 | PM 维护 **20 大类 × 50 国** 规则矩阵 + `building-wiki` RAG |
| **M1** | 蓝海雷达卡片（目的国增速、竞争度） | 海关 **公开统计** + 本站 SEO/询盘信号 |
| **M2** | 建材版「出海生意参谋」 | 商业海关数据 API（旗舰套餐） |

**UBrain 承接问答**；界面仅 **卡片 + 助手**，不新增顶层菜单。页脚免责声明必显。

**运营 SOP**：客服 **先助手、后人工**；微信群高频问题每周回填矩阵。

### 2.8 出海计 App（租户商家端 · **必做** · 豆包式）

> 展开版：`docs/出海计-App产品规格.md`（原「优丁 App」文档已迁移）

#### 2.8.1 命名（已定稿）

| 名称 | 用途 |
|------|------|
| **出海计** | **App 正式名称**（应用商店、图标、法务文本） |
| **优丁助手** | App 内 AI 对话功能品牌（= UBrain） |
| **优丁建材 OS** | 公司与 Web 后台母品牌 |
| **出海季** | **仅营销活动**（峰会/战役/季度促销），**不得**作为 App 名或包名 |

**包名建议**：`com.youding.chuhaiji` · 显示名：**出海计**

#### 2.8.2 为什么要做（必做，非 P2 可砍）

| 角色 | 理由 |
|------|------|
| 租户老板 | 不在电脑前也要 **秒回询盘、看发布、问出口** |
| 运营/客服 | 减少微信问「能做出口吗」；Push 拉回访 |
| 融资/政府 | 「移动端 + AI 决策」可演示，区别于普通后台 |
| 产品战略 | Web 四支柱收口后，**手机主入口 = 助手**，与豆包同级体验 |

## 四、关键产品规则（研发必须遵守）

### 4.1 发布与链接

| 场景 | 规则 |
|------|------|
| 40 平台帖子 | **主链** → 租户 `tenant_canonical_url`；**次链** → 总站枢纽页（仅站外） |
| 租户独立域正文 | `canonical` **必须**指向租户自己的 URL |
| 租户站前台 | **不得**出现总站隐藏友链、透明字、强制 canonical 指总站 |
| 总站枢纽页 | URL：`/industry/{tenant_slug}/{content_id}/`；正文链回租户全文 |

### 4.2 网络与执行

| 区域 | 执行方式 |
|------|----------|
| 国内平台 | 国内 Worker + 国内静态 IP + 指纹 |
| 海外平台 | **平台托管** 海外 Worker + 当地静态 IP；**租户不自备翻墙** |

### 4.3 呼朋唤友「有效邀请」

注册 + **企业认证** + **首笔付费**（与方案文档一致）→ 才计入 L1/L3/L5 与排行榜。

### 4.4 管理端登录（超管 / 代理 / 租户）

| 规则 | 说明 |
|------|------|
| 统一 API | `POST /api/v1/auth/login`（密码）；第三方走 `/auth/oauth/*` + `/auth/third-party-login` |
| 统一页面 | 管理端 `/login`；租户后台 `/client/login`（同一 auth 服务） |
| 角色分流 | JWT `role`：`tenant_admin` → 客户工作台；其余 → `/admin`（代理 L1～L5 为菜单能力，非独立登录） |
| 第三方安全 | 仅 **已绑定** `third_party_logins` 的用户可 OAuth 进管理端；开发环境可用 `OAUTH_DEV_BYPASS` |
| OAuth 回调 | 平台只回 `code`+`state`，**provider 必须从 state JSON 解析** |

**详细对接、环境变量、验收命令**：见 [`管理端统一登录与OAuth对接.md`](管理端统一登录与OAuth对接.md)。

### 4.5 体验与对外演示

| 规则 | 说明 |
|------|------|
| 演示脚本 | **七步 30 分钟**（①开通→②绑域→④发布→⑤询盘→⑦运单），见 `演示验收清单.md` |
| 禁止对外 | 未接 API 的实验室页、纯 localStorage 能力导航当生产演示 |
| 政府/融资 | 材料与 staging **一致**；附 `战略总纲-2026` + 彩排录屏 |
| 菜单冻结 | 体验 Sprint 期间 **不新增顶层菜单**；新能力进四支柱或 UBrain |

### 4.6 出海参谋回答规范

| 规则 | 说明 |
|------|------|
| 必含 | HS 或品类依据、能/慎/难、下一步动作链接 |
| 禁止 | 宣称与淘宝生意参谋同源、无法律免责声明 |
| 维护 | PM 每周审 **国家×品类** 矩阵；运营提交客服实录 |
