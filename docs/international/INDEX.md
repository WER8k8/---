# 国际订单采集系统 — 文档总索引

> 本文档是优丁建材国际订单采集系统的文档入口。系统采用 **Cloudflare Workers（海外节点）+ 阿里云轻量服务器（国内）** 的混合架构，实现跨境建材询盘信息的自动采集、提取与同步。

---

## 系统架构简介

```
┌─────────────────────────────────────────────────────────────┐
│                    Cloudflare Workers（海外）                  │
│                                                             │
│  ┌──────────┐    ┌──────────────┐    ┌──────────────────┐   │
│  │ 爬虫 Worker│───▶│ NLP 提取 Worker│───▶│ 加密传输 Worker  │   │
│  │ (网页抓取) │    │ (信息结构化)  │    │ (AES-256 加密)   │   │
│  └──────────┘    └──────────────┘    └────────┬─────────┘   │
│                                                │             │
└────────────────────────────────────────────────│─────────────┘
                                                 │ via HTTPS (TLS 1.3)
                                                 ▼
┌─────────────────────────────────────────────────────────────┐
│                    阿里云轻量服务器（国内）                      │
│                                                             │
│  ┌──────────┐    ┌──────────────┐    ┌──────────────────┐   │
│  │ Nginx    │───▶│ Webhook 服务  │───▶│ PostgreSQL 数据库 │   │
│  │ 反向代理  │    │ (数据接收+解密)│    │ (持久化存储)      │   │
│  └──────────┘    └──────────────┘    └──────────────────┘   │
│                      │                                       │
│                      ▼                                       │
│              ┌────────────────┐                              │
│              │ Admin 管理界面  │                              │
│              │ (数据查看/管理) │                              │
│              └────────────────┘                              │
└─────────────────────────────────────────────────────────────┘
```

**数据流向：** 海外建材网站/B2B 平台 → Cloudflare Workers 抓取爬虫 → NLP 提取询盘信息 → AES-256 加密 → HTTPS 传输至阿里云服务器 → Webhook 解密入库 → Admin 后台管理

## 快速参考

### 关键地址（示例）

| 组件 | 地址 |
|------|------|
| Cloudflare Workers | `https://crawler.you-ding-brick.workers.dev` |
| Webhook 接收端点 | `https://api.youdingbrick.com/webhook/inquiry` |
| Admin 管理后台 | `https://admin.youdingbrick.com` |
| 数据库 | `postgresql://user:pass@localhost:5432/international` |

### 技术栈

| 技术 | 版本 | 用途 |
|------|------|------|
| Node.js | 18+ | Cloudflare Workers 运行时 |
| Python | 3.11+ | Webhook 服务、Admin 后端 |
| PostgreSQL | 15+ | 数据持久化存储 |
| Nginx | 1.24+ | 反向代理、SSL 终止 |
| Wrangler | 3.x | Workers 部署管理 |
| Celery | 5.x | 异步任务队列（可选） |

- **每月**：配额趋势分析 + 安全更新检查 + 备份完整性验证
