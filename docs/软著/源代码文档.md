## 软件技术特点

1. **多租户 SaaS 架构**：基于子域名的租户隔离，支持独立品牌站点配置。
2. **AI 多模型调度引擎**：自适应选择 GPT-4、Claude、通义千问等大模型。
3. **多平台内容分发**：一键同步内容至微信、抖音、飞书等平台。
4. **SEO 智能优化**：自动生成 Schema 结构化数据、元标签优化。
5. **认知引擎**：语义索引与问答系统，支持建材行业知识库。
6. **全链路安全**：JWT + CSRF + 速率限制 + WAF 多层防护。
