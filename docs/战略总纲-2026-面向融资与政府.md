# 优丁建材 AI 卖货 OS — 2026 战略总纲（融资 · 政府申报 · 产品方向）

> **读者**：创始人、投资人、政府评审、全体研发  
> **版本**：V1.0 · 2026-05-24  
> **原则**：不整库换框架；分壳体验；AI 减步骤不减控制；每月可演示里程碑

## 一、用大白话说明：我们到底是什么

**一句话**：给建材外贸企业一套「独立官网 + AI 写内容 + 40 平台分发 + 询盘成交 + 物流可查」的 **云端操作系统**，按 **套餐 + AI 用量 + 独立 IP** 收费。

**不是什么**：不是又一个乱菜单的后台；不是实验室堆功能的 Demo；不是换皮 RuoYi。

**技术事实（给专业人员看）**：

- 后端：**FastAPI**，700+ 已挂载 API，多租户与超管分域  
- 前台：**Nuxt 3** 访客站 + **Vue 3 管理端**（Ant Design Vue）  
- 排期研发 Sprint **84/84 已完成**；产品商用全景约 **76%**（差生产环境彩排与体验收口）

## 二、为什么「全搬 RuoYi + Soybean」不做

| 若全搬 | 后果 |
|--------|------|
| 换 Java 后端 | 已写好的 Python 业务全部重写，**1～2 年商用停摆** |
| 换 Naive/Element 前端 | 200+ 页面重写，**投资人看到的仍是半成品** |
| 双栈并存 | 维护成本翻倍，**更容易像「垃圾」** |

**最优解**：**业务与 API 不动**；**四套界面壳 + 2026 设计规范 + AI 调度大脑** 渐进升级（12～18 个月，每月能演示）。

详见：`docs/四壳信息架构与菜单治理.md`、`docs/UBrain-统一调度大脑-产品规格.md`。

**七步闭环**（政府与投资人必讲）：

1. 开通 SaaS → 2. 独立域 HTTPS → 3. 统一母版 → 4. 40 平台分发 → 5. 询盘 IM → 6. 订单报价 → 7. 物流可查  

**三轨收入**：租户订阅 · AI Token · 静态 IP 槽位（见 `docs/产品俯视-租户旅程与三轨计费.md`）。

## 四、2026 产品方向（把握方向 · 注重细节）

### 方向 1：体验像「产品」，不像「功能仓库」

- 租户登录只见 **4 个支柱**：获客 / 发品 / 履约 / 账户  
- 首页只有 **「今日一件事」** + 进度条（域、发布、未回询盘）  
- 超管分 **三区**：运营 / 商业 / 治理；实验室功能默认关闭  

### 方向 2：AI 是「副驾」，不是「菜单」

- 用户说：「帮我回这条询盘」「发一篇到已选平台」「域名 SSL 好了吗」  
- 由 **UBrain 调度大脑** 拆任务、调 API、汇报结果（见 UBrain 规格）  
- **越用越聪明**：只沉淀 **脱敏后的操作习惯与模板**，不泄露租户数据  

### 方向 3：生产可信（专业人员不骂街）

- HTTPS 真签发、支付验签、cron 冻结、发布队列可追踪  
- 每个长任务：**进行中 / 成功 / 失败原因 / 重试**  
- 对外演示：**固定一条 30 分钟彩排脚本**（注册→绑域→发布→询盘→运单）  

### 方向 4：不跑专业路线也能卖

- 向导代替培训；默认配置代替表单  
- 代理壳只显示佣金、开户、客户，不暴露超管实验室

## 五、执行路线图（不怕长，怕干不好）

| 阶段 | 时间 | 交付（可演示） | 商业价值 |
|------|------|----------------|----------|
| **P0 可信** | 0～2 月 | HTTPS 演示域、支付/cron 上线、七步彩排视频 | 政府/客户信得过 |
| **P1 租户壳** | 2～5 月 | `/client` 四支柱 + Onboarding 向导 | 客户觉得简单 |
| **P2 超管壳** | 5～9 月 | 三区布局、菜单减半、Ctrl+K | 运营效率 |
| **P3 代理壳** | 9～12 月 | `/agent` 独立 + 数据权限 | 渠道可复制 |
| **P4 UBrain** | 贯穿 6～18 月 | 副驾 v1→记忆 v2→工作流 | 差异化与续费 |

**冻结规则**：每阶段 **禁止新增顶层菜单**；新能力必须进四支柱或 UBrain 指令。

## 九、盈利与回血（创始人关心）

1. **先卖「七步包」套餐**：基础版（域+站+询盘）→ 专业版（+发布 20 平台）→ 旗舰（+IP+40 平台）  
2. **Token 包毛利**：模型路由 + 缓存模板，控制成本（超管 ai-cost 已有）  
3. **代理分润**：L2 开户即锁客，续费分成（`referral` 已起步）  
4. **不做**：未验收的 GEO/RAG 当主卖点卖
