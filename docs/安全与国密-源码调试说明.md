# 安全与国密 · 源码调试说明（国密 + 微信唯一）

> 需求来源：`wang zhan\.trae\rules\轻集料混凝土网站开发规则.md`  
> **日常入口**：管理端 → **超级管理员 → 创始人诊断**（`/admin/founder-diagnostics`）

---

## 一、你怎么用（不用 SSH）

| 步骤 | 操作 |
|------|------|
| 1 | 浏览器打开管理后台，**超管账号**登录 |
| 2 | 进入 **创始人诊断**，点 **去绑定微信**（本人微信扫码） |
| 3 | 复制页面上 `FOUNDER_WECHAT_OPENID=wechat_xxx`，写入服务器 `.env.prod`，重启后端 |
| 4 | 回到本页点 **运行诊断**、**国密自检** |

改代码、修 BUG：在本机 **Cursor** 打开仓库即可，**不必**登录云服务器改 Python。

---

## 二、门禁规则（别人进不来）

生产推荐 **只配微信，不配令牌**：

| 条件 | 说明 |
|------|------|
| 角色 | `super_admin` 或 `admin` |
| 微信 | 当前账号绑定的微信 ID = `FOUNDER_WECHAT_OPENID` |
| IP（可选） | `FOUNDER_DEBUG_IPS` 白名单 |

开发环境可暂用 `FOUNDER_DEBUG_TOKEN`（请求头 `X-Founder-Debug-Token`），**生产请以微信为准**。

## 三、环境变量

```env
# 创始人绑死（你的微信号，已写入示例配置）
FOUNDER_WECHAT_BIND_KEY=qq979072138
FOUNDER_WECHAT_OPENID=wechat_qq979072138
FOUNDER_ADMIN_USERNAME=qq979072138

# 可选：仅允许这些 IP 访问创始人接口
FOUNDER_DEBUG_IPS=你的公网IP

# 国密
GM_SM4_KEY=

# 微信 OAuth（绑定必备）
WECHAT_OPEN_APP_ID=
WECHAT_OPEN_APP_SECRET=

# 开发兜底（生产可留空）
FOUNDER_DEBUG_TOKEN=
```

## 四、API（管理端已封装，一般不必手调）

| 方法 | 路径 | 谁可访问 |
|------|------|----------|
| GET | `/api/v1/founder-ops/preflight` | 超管（查绑定与配置说明） |
| GET | `/api/v1/founder-ops/status` | 超管 + 创始人微信 |
| GET | `/api/v1/founder-ops/crypto/self-test` | 同上 |
| GET | `/api/v1/founder-ops/protection-summary` | 同上（鉴定摘要） |
| GET | `/api/v1/founder-ops/security-events` | 同上（安全留痕） |

**成果保护**：`EXPORT_PLATFORM_FOUNDER_ONLY=true` 时，全平台 CSV 导出仅创始人；每次导出与拒绝写入 `operation_logs`。详见 `docs/成果保护与第三方鉴定清单.md`。
