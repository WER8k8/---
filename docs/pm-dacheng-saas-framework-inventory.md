## 一、老板一句话版（给小学文化也能讲）

**现在有什么？**  
一套「工厂卖货软件」的 **架子已经搭好**：能开户、能建站、能管产品、能写内容、能发多个平台、能收询盘、能写开发信、能看 SEO/GEO 监测。

**还差什么？**  
不是再堆菜单，而是 **大城真实工厂跑通**：产品真实、内容真实、发布真实、电话真实、账算得清——**细节和闭环**。

**是不是 OS？**  
**还不是。** 现在是 **「大城建材外贸 SaaS 1.0 内核」**；OS 要等 10 家厂子反复用、数据闭环、行业模板可复制。

## 二、战略阶段（产品路线，不是作战图）

| 阶段 | 范围 | 成功标准（可验收） |
|------|------|-------------------|
| **A · 基本盘**（0～12 月） | 大城 / 河间 / 廊坊 **保温建材**（岩棉、玻璃棉、橡塑、聚氨酯、挤塑等） | 10～30 家真实工厂；**可回拨询盘**；开发信/内容 **绑定产品库** |
| **B · 建材扩张**（12～24 月） | 瓷砖、铝材、防水、管道… | 换 **行业模板 + 词库**，不换系统内核 |
| **C · 跨行业 OS**（24 月+） | 机械、食品、汽配… | 每行业必须带：产业带 + 产品库 + 合规 + 案例，否则不开包 |

**永久原则**（[`no-fake-delivery-charter.md`](./no-fake-delivery-charter.md)）：  
不造假数据、不假装排名、不自动乱发开发信；**发送前人工确认**。

## 三、系统分层：现在框架 vs 还缺的细节

```text
┌─────────────────────────────────────────────────────────────┐
│  L4 商业层  套餐 · Token · 续费 · 代理分润 ·  honest 报表   │  🔄 框架有，细节弱
├─────────────────────────────────────────────────────────────┤
│  L3 体验层  四支柱导航 · 开户向导 · 「今日三步」极简操作      │  🔄 菜单多，极简未落地
├─────────────────────────────────────────────────────────────┤
│  L2 能力层  七步卖货闭环 · UBrain/Accio · SEO/GEO/矩阵      │  ✅ 模块齐，接线未全
├─────────────────────────────────────────────────────────────┤
│  L1 工程层  多租户 · FastAPI · Admin/Client · cert:gate      │  ✅ 可运行
└─────────────────────────────────────────────────────────────┘
```

### 3.1 七步卖货闭环（框架已画，细节待钉）

| 步骤 | 租户要的结果 | 已有模块（代码/菜单） | 框架完成度 | 还缺的关键细节 |
|------|--------------|----------------------|------------|----------------|
| **① 开户识货** | 填产品、产地，系统知道卖什么 | 注册、`primary_product`、产业带 JSON、产品画像服务 | 🟡 70% | 强制产品库；大城/河间默认产业带 UI |
| **② 建站资产** | 独立域、像样官网 | Hermes 建站、`/client/onboarding`、站点编辑器 BJ-01 | 🟢 85% | 租户独立域绑定率；与产品库联动 |
| **③ 让人看见** | SEO + GEO + 矩阵曝光 | SEO 工具箱、SEO 矩阵、GEO 引擎、统一发布台 | 🟡 65% | 排名 honest；百度 Token；GEO Key；大城长尾词表运营 |
| **④ 内容生产** | 专业文章/视频/多语言 | 建材百科、内容优化、媒体工厂、GEO 内容矩阵 | 🟢 80% | 必须引用真实规格；**视频改「两图出片」轻编排**（见 `pm-lightweight-video-strategy.md`） |
| **⑤ 收询盘** | 表单/IM/电话进系统 | 询盘管理、IM 路由、访客上下文 | 🟡 70% | 全渠道进 inbox；响应 SLA 报表 |
| **⑥ 卖出去** | 开发信、谈单、报价、订单 | Accio 开发信/找客/谈单、报价/订单模块 | 🟡 60% | 开发信←产品库；按国家语言；成交回写 |
| **⑦ 算清账** | 知道钱花哪、赚没赚 | 数据中心、Token 账本、经营日报 | 🔴 45% | 线索成本 =（年费+Token）/ 有效询盘 |

图例：🟢 可用 · 🟡 有框架缺细节 · 🔴 骨架/待建

## 六、按业务域列「已有框架」（研发资产清单）

### 6.1 账户与开户（L4/L3）

- 邮箱注册 + 验证码、套餐、邀请码、平台槽位预置  
- Onboarding  checklist / 外链账号清单 / 一键开业 Autopilot  
- 租户记忆（品类、区域、开发信语言）、**产品画像**（产品库→产业带→联网调研）  
- Token 配额、Egress IP 分配  

### 6.2 产品与内容（发品）

- 产品 CRUD、分类、图片、规格参数  
- CMS 内容页、案例、新闻  
- Formily 站点编辑器（BJ-01）、Hermes ECC 建站流水线  

### 6.3 推广与可见性（SEO + GEO）

- **SEO**：概览、站点体检、llms.txt、合规扫描、关键词库、rank/check 爬虫  
- **SEO 矩阵**：省市区县词、生成、发布、收录监控  
- **GEO**：AI 模型探测（配 Key）、统一发布台、内容矩阵任务  
- 增长工具：热词、流量引擎注册表、探针状态  
- ⚠️ 可信度分档：[`admin-seo-geo-data-trust-map.md`](./admin-seo-geo-data-trust-map.md)

### 6.4 卖货与外贸（Accio / UBrain）

- 卖货副驾、意图编排（找客、开发信、谈单、出口可行性、旺财…）  
- 开发信专员 + 可达性（质量分、时区、垃圾箱词）  
- 外贸团队页、DeerFlow 研究、飞轮工作流  
- 专家角色库 `b2b_trade_experts.json`（8 角色映射）  

### 6.5 成交与履约

- 询盘、报价、订单、支付（微信/支付宝 mock 门控）  
- 物流定价、发票、WorldFirst 等扩展  

### 6.6 平台与治理

- 多租户 RBAC、代理层级（MOD-09）  
- Agent Hub、Super Agent、Ops 诚实 standup  
- cert:gate、假数据门禁、送检脚本与 Stub 隐藏  

### 6.7 侧车（可选，生产增强）

- Headless GEO 探针、DeerFlow、视频 Worker、爬虫 Sidecar（见 `deploy/docs/*`）

## 七、与「SAAS+GEO 巨头」差在哪（诚实差距表）

| 巨头能力 | 我们现状 | 大城阶段要不要 |
|----------|----------|----------------|
| 稳定关键词/SERP API | 爬虫 + 易变模拟 | 要：百度站长 Token + 付费 SERP |
| 真实 AI 搜索快照（Perplexity/AIO） | 多数「探索中」 | 中后期 |
| 全链路归因（UTM→询盘→订单） | 部分 UTM，未闭环 | **要，P0** |
| 行业模板市场 | 仅建材/大城产业带 JSON | **要，基本盘** |
| 极简「今日三步」 | 菜单 90+ | **要，P0 体验** |
| 生态/marketplace | Agent Hub 雏形 | 阶段 C |

**结论**：框架宽度 **接近中型 SaaS**；深度与 ** honest 闭环** 仍属早期——符合「路漫长」的判断。

## 九、PM + 产品「只盯细节」的优先队列（框架已有）

与老板痛点 **推广难、排名难、卖货少** 直接相关，**90 天内框架内填细节**：

| 优先级 | 细节项 | 归属部门 | 验收 |
|--------|--------|----------|------|
| **P0-1** | 产品库 → 建站 / 开发信 / SEO **强制引用** | 后端+产品 | 无产品不能生成开发信 |
| **P0-2** | Client **「今日三步」** 单页（填产品→发内容→看询盘） | 产品+前端 | 老板 3 分钟内完成一次 | ✅ `/client/today` |
| **P0-3** | SEO/GEO 页面 ** honest 黄条**（模拟/未配 Token） | 前端+PM | trust-map 每条落地 | ✅ YdHonestDataBanner |
| **P0-4** | 收录监控 **生产必开** + 大城长尾词表入库 | SEO+运营 | 发布 URL 有收录复检记录 | ✅ 词库+导入+probe-config |
| **P0-5** | 询盘 **全进 inbox** + 周报（来了几条、跟进了几条） | 后端+CS | 数字可为 0，不可假 | ✅ `/client/inquiry-weekly` |
| **P0-1** | 产品库 → 建站 / 开发信 / SEO **强制引用** | 后端+产品 | 无产品不能生成内容 | ✅ 开发信+百科+矩阵+内容包 |
| **P1-1** | 百度站长 Token 对接指引 + 绑定率 | 运营+前端 | 有 Token 则非 mock |
| **P1-2** | 开发信 **按买家国家建议语言** | GW-L | 界面可见建议 |
| **P1-3** | UTM → 询盘来源字段 | GW-P | 至少 1 条链路演示 |

**明确不做（阶段 A）**：C 端娱乐爆款、220 个空壳 Agent、未验证行业的行业包。

## 十、给老板汇报用的三句话

1. **框架有了**：开户、建站、产品、SEO/GEO、矩阵发布、副驾卖货、询盘订单——**一条链上的模块都在仓库里**。  
2. **还不是 OS**：缺的是大城真实工厂跑出来的 **细节、闭环、 honest 数字**，不是再堆 50 个菜单。  
3. **路对了但长**：先让 **大城 10 家保温厂多接电话**，再谈建材全行业，再谈「文盲也能卖海外」——产品和 ECC 200 人按上表 **填细节**，不空转。
