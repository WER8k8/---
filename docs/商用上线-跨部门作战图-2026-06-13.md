## 一、结论（给决策层 30 秒）

| 判断 | 说明 |
|------|------|
| **现在像半成品？** | ✅ 准确。代码 Sprint 已闭合，**产品商用约 78%**，大量入口是导航索引或实验室壳。 |
| **能否明天商用？** | ❌ 不行。缺 PM 签字、演示域、送检截图链、实验室 Kill 决策、生产预检实机一轮。 |
| **到大厂标准要多久？** | **分三阶**：鉴定面商用 4～6 周 · 主链全商用 8～12 周 · 出海计商店 + 差异化 12～18 周（可并行，非一刀切）。 |
| **谁牵头？** | **PM-07 调度**；**产品定范围**；研发不猜需求；运维握生产钥匙。 |

**大厂标准在这里的定义**：不是菜单越多越好，而是 **可演示、可计费、可观测、可追责、可送检**——且 **无假交付**（`validate-no-fake-delivery.py` P0=0）。

## 四、三阶路线图（到大厂标准商用）

### 阶段 1 · 鉴定面商用（4～6 周）— **先能收钱、能演示、能送检**

**范围**：`stubVisibility.ts` → `CERT_INSPECTION_MENU` 内能力 + 七步闭环 + 出海计 PWA（非商店包）。

| 周 | 产品 | PM | 研发 | 运维/QA |
|----|------|-----|------|---------|
| W1 | 送检清单签字；Stub Kill 清单 v1 | 演示域 DNS；Owner O-1 催办 | 主链 P0 回归；去假 KPI 复核 | staging preflight 0 fail |
| W2 | 四壳菜单删留签字 | 12 截图分工 | PlanGate 页文案；询盘手机必填复核 | 流量管道 `verify_traffic_pipeline` |
| W3 | SEO 信任图一页对外版 | 七步录屏彩排 | 发布 Worker 生产观测 | 备份演练 |
| W4 | 套餐价表签字 | l3-signoff PM 签 | MVP 预检修红项 | `deploy-mvp-production.ps1` 实跑 |
| W5～6 | 试点客户 1 家陪跑 | 验收会 | 热修 only | HTTPS 独立域 SSL 真签发 |

**阶段 1 退出标准**：G1～G5 全绿；对外只说送检清单内能力；`MVP_LAUNCH` 可开但 AI 降级须标注。

---

### 阶段 2 · 主链全商用（+8～12 周）— **租户日常不用进实验室**

**范围**：租户四支柱 + 财务 + 矩阵发布 + 出海参谋 M1 + 物流实单 + 发票 PDF。

| 能力 | 产品交付 | 研发交付 |
|------|----------|----------|
| IM 全渠道 | 租户站组件规范 | P1-01 |
| 发票/账单 PDF | 模板样式签字 | P1-08 |
| 生产邮件 | 邮箱策略 | P1-07 SMTP |
| 物流 | 快递100 或自研 SLA | kuaidi100 生产 Key |
| 裂变非 Token | 奖励类型表 | P1-06 |
| GEO 可售 | 能力项与 probe_ready 边界 | Hermes HRANK 分批 |

**阶段 2 退出标准**：租户路径无 mock 假成功；`admin_lab_enabled` 默认 0；超管工作台仅真实探针。
