## W19 支付宝沙箱探针

**脚本** `backend/scripts/alipay_sandbox_probe.py`

```powershell
cd backend

# 检查 ALIPAY_* 是否齐全
python scripts/alipay_sandbox_probe.py --check

# 沙箱 precreate（.env 中 ALIPAY_GATEWAY=https://openapi.alipaydev.com/gateway.do）
python scripts/alipay_sandbox_probe.py --precreate --amount 99 --subject "联调"

# 向本地后端 POST 模拟 TRADE_SUCCESS（需 PAYMENT_STRICT_VERIFY=0）
python scripts/alipay_sandbox_probe.py --mock-notify `
  --notify-url http://127.0.0.1:8001/api/v1/payment/notify/alipay `
  --order-no 你的待支付订单号 --amount 99.00
```

## W20 微信独立回调

**路由** `POST /api/v1/payment/notify/wechat`

- 接收微信支付 v3 原始 JSON body
- `PAYMENT_STRICT_VERIFY=1` 时校验 `Wechatpay-*` 头（需 `WECHAT_PAY_PLATFORM_PUBLIC_KEY`）
- 响应：`{"code":"SUCCESS","message":"成功"}`

**默认 notify_url** 已改为 `/api/v1/payment/notify/wechat`

```
WECHAT_PAY_NOTIFY_URL=https://你的域名/api/v1/payment/notify/wechat
WECHAT_PAY_PLATFORM_PUBLIC_KEY=
```
