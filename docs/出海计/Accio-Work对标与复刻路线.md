# Accio Work 对标与「可复刻」路线

> 版本：2026-05-25  
> 目的：回答「Accio 强不少，咱们能不能复刻」——**能复刻的是形态与闭环，不能复刻的是阿里国际站私有数据与官方授权执行权**。

**产品铁律**：对外卖货 OS 的主轴固定为 **字节 DeerFlow（研究）+ 阿里 AccioWork（执行）** 同款能力树；PM/设计只排期与 gap，**不另起炉灶改主方向**。见 `DeerFlow-Accio-能力对标与本系统映射.md`。

---

## 一、Accio Work 到底是什么（两个层面别混）

| 层面 | 代表能力 | 护城河 |
|------|----------|--------|
| **阿里国际 Accio Work**（2026-03 发布） | 国际站插件：选品洞察、发品生图、广告诊断、店铺经营报告、**询盘/聊天意向分级**、RFQ/邮件多轮砍价、VAT/海关合规 | **阿里巴巴国际站账号、广告、交易、物流数据与写操作 API** |
| **accio.com 桌面版** | Electron 本地优先、**浏览器 CDP 自动化**、终端、MCP/Skills 市场、Telegram/飞书/微信等通道 | 客户端执行环境 + 技能生态 |

公开报道归纳的「七大插件」：选品、发品、广告、经营分析、客户接待、物流查税、风险防护（见 PR Newswire / 腾讯新闻 2026-03～04）。

## 二、咱们已经有的（不必从零抄）

| Accio 叙事 | 优丁现状 | 差距 |
|------------|----------|------|
| 一站式工作台 | 租户四支柱 + 七步闭环 + 超管治理 | 缺 **单一「副驾工作台」** 聚合入口（UBrain 未全挂 UI） |
| AI 写内容并发 | `content_master` + 发布 Worker + SEO/GEO API | **40 平台 PM 表、cron、真 OAuth** 未齐 |
| 独立站承接询盘 | `/inquiries/public` + 后台 unified | 表单 **手机必填**、意向分级、聊天记录导入 **未做** |
| 贸易情报 | 出海参谋 M0 + UBrain `export_feasibility` / `blue_ocean` | 无阿里站内 **选品/竞价** 数据 |
| 多通道 | IM 路由骨架、StickyImBar | 无 Accio 级 **企微/抖音私信全自动代发**（需授权+合规） |
| 安全执行 | — | 需 **沙箱 + 分级审批**（付钱/改价/对外发信默认人工确认） |

**UBrain v1 已有意图**：询盘草稿、发布状态、SSL、出口可行性、蓝海、HS 查询（`backend/app/services/ubrain/orchestrator.py`），但询盘草稿仍是示意文案，未接真实 LLM 与线索库。

## 三、不能 1:1 复刻的部分（说透，避免融资话术翻车）

1. **国际站私有 Skills** — 无阿里合作拿不到同等选品、广告、RFQ 执行权限。  
2. **「零配置就能替商家谈价」** — 涉及合同与邮箱授权，需法务边界；建议只做 **草稿 + 人点发送**。  
3. **100 国 VAT 实时申报** — 需各国税务接口与资质，短期只能做 **清单/模板/提醒**，不能做自动申报。  
4. **千万级月活与模型成本** — 阿里体量；咱们按 **租户 Token 计费** 控成本。  
5. **桌面本地 Agent（accio.com）** — 与咱们 **云端 SaaS** 路线不同；可做 **出海计 App / 可选桌面壳**，非 P0。

## 四、建议复刻的「产品形态」（Accio-like，但建材垂直）

目标：**一个工作台 + 一支 Agent 舰队 + 敏感操作必确认**，嵌在现有 `/client`，不重写后端。

```
租户说一句话
    → UBrain Orchestrator（意图）
    → 工具：询盘分析 | 发布 | SEO报告 | 出海参谋 | 域名SSL
    → 需确认：对外发送 / 改价 / 扣 Token 大额
    → 结果回写：询盘状态 / 发布队列 / 今日一件事
```

### 与 Accio 的差异化（卖给客户的话）

- Accio 强在 **阿里国际站内**；咱们强在 **建材垂直 + 自有独立域 + 国内 20 + 海外 20 矩阵 + 三轨计费（SaaS/Token/IP）**。  
- 不做「替代国际站」，做 **「独立站 + 全网矩阵 + 贸易情报」操作系统**。

## 五、分阶段复刻清单（可验收）

### Phase A — 4～6 周（「像 Accio 的工作台」，不碰阿里 API）

| 项 | 交付 | 复刻 Accio 哪块 |
|----|------|-----------------|
| A1 | Client 顶栏 **「卖货副驾」** 单页：对话 + 任务卡片 | 统一工作台 |
| A2 | UBrain 接真实 LLM + **询盘列表上下文** 生成回复草稿 | 客户接待 |
| A3 | **询盘意向评分**（规则+模型）：高/中/低 + 跟进建议 | 意向分级 |
| A4 | **经营快照**：未回询盘、发布失败、SSL 过期（只读聚合） | 店铺诊断（轻量） |
| A5 | 所有对外动作 **二次确认** + 审计日志 | 安全边界 |

### Phase B — 2～3 月（执行型 Agent，仍非国际站）

| 项 | 交付 |
|----|------|
| B1 | **5+5 平台** 发布 Worker + 浏览器配置（`browser_profile` + static IP） |
| B2 | SEO/GEO **一键诊断报告** PDF/飞书推送 |
| B3 | 聊天记录 **导入**（粘贴/上传）→ 意向分析 |
| B4 | `ubrain_tenant_memory`：记住平台勾选、语气模板 |

### Phase C — 6～12 月（可选，有客户再投）

| 项 | 说明 |
|----|------|
| C1 | **国际站/1688 开放 API 插件**（若签合作），不做黑盒爬站内 |
| C2 | RFQ **草稿链**（多轮话术建议，人发邮件） |
| C3 | 合规 **知识库**（国别清单 + 单据模板），非自动报税 |
| C4 | 出海计 **Electron 壳**（本地浏览器任务），服务大客户 |
