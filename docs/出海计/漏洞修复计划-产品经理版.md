## P0：已在代码库落地的依赖升级（本轮）

| 包 | 原风险 | 处理 |
|----|--------|------|
| `cryptography` | 多条 CVE | 显式 `>=44.0.1` |
| `pymysql` | CVE-2024-36039 | `>=1.1.1` |
| `python-multipart` | 上传 CVE | `>=0.0.18` |
| `python-jose` | JWT CVE | `>=3.4.0` |
| `python-dotenv` | CVE-2026-28684 | `>=1.2.2` |
| `lxml` | PYSEC-2026-87 | `>=5.3.0` |
| `langchain==0.1.10` | 整链老旧 | **移除**，改为 `langchain-core` 等 0.3.x |

**验收**：在 `backend` 执行：

```powershell
pip install -r requirements.txt
python -m pip_audit
python -m pytest tests/unit -q --tb=no
```

**实测（本机 venv 复验）**：`pip-audit` 由约 **74 条 → 31 条**（卸载遗留 `langchain==0.1.10` 并升直接依赖后）。  
目标：生产用**独立 venv** 安装，勿混全局 `httpie` 等工具包；剩余多为 `pypdf`/`pytest` 传递依赖，P1 继续压。
