# 夜间无人全自动开发模式

> **版本**：2026-05-25  
> **前提**：开发主线见 [商业飞轮OS-开发总文档.md](./商业飞轮OS-开发总文档.md)（字节 DeerFlow + 阿里 Accio 对标，飞轮三柱）。  
> **定位**：人睡后，**Agent 写代码 + 脚本跑门禁**；明早只看 `MORNING.md` / `GATE_REPORT.md`。

---

## 一、两层架构

| 层 | 做什么 | 工具 |
|----|--------|------|
| **机械层** | pytest、路由检查、生成 Agent 提示与日志 | `scripts/night-autodev.ps1` |
| **智能层** | 读队列、最小实现、自测、写晨间交接 | Cursor Agent / Cloud Agent + `workflows/night-autodev-flywheel.yaml` |

**不要**每晚跑完整 `agency-ecc-full.yaml`（222 人七阶段）— 太慢、易偏航。夜间只用 **飞轮专用工作流**。

---

## 二、睡前 3 分钟（操作清单）

1. **保存并提交**当日想保留的改动（可选；夜间 Agent **默认不 push**）。
2. **跑机械门禁**（生成明早目录）：

```powershell
cd "C:\Users\97907\Desktop\UJ\website CodeBuddy"
powershell -ExecutionPolicy Bypass -File scripts/night-autodev.ps1
```

3. **启动智能层**（三选一）：

| 方式 | 操作 |
|------|------|
| **A. Cursor 后台 Agent** | 新 Background Agent → 粘贴 `.ao-output/night-autodev-YYYY-MM-DD/AGENT_PROMPT.md` 全文 |
| **B. 固定循环** | 对话输入：`/loop 2h` + 粘贴 AGENT_PROMPT（每 2 小时续跑队列，见 Cursor loop 技能） |
| **C. 工作流** | 对话说明：按 `workflows/night-autodev-flywheel.yaml` 执行，`task` 可留空 |

4. **确认队列**：编辑 `docs/出海计/night-autodev-queue.yaml`，把「本夜要做」的项排到前面（P0 优先，每晚最多 **3** 条）。

---

## 三、任务队列

- **文件**：`docs/出海计/night-autodev-queue.yaml`
- **规则**：`max_tasks_per_night: 3`；`forbidden` 内事项一夜不做。
- **完成标记**：Agent 在 `MORNING.md` 写明 `N1 done`；人工次日把 yaml 里对应项加 `status: done` 或删掉。

默认队列含：pipeline API、副驾轮询、n8n 示例、反馈 cron 脚本等（均服务飞轮 P0/P1）。

---

## 四、工作流（智能层）

- **文件**：`workflows/night-autodev-flywheel.yaml`
- **步骤**：读队列 → 架构铁律审查 → 实现 → pytest → code-review → `MORNING.md`
- **ECC 角色**：`.cursor/agents/`（code-reviewer、testing-reality-checker 等）
- **Agency 角色**：`~/.claude/agents/`（orchestrator、devops-automator）

触发方式：对 Cursor 说「按 night-autodev-flywheel 工作流执行夜间开发」或加载 `workflow-runner` 技能后指定 yaml。

---

## 五、硬约束（与产品铁律一致）

| 必须 | 禁止 |
|------|------|
| 只改队列 `paths` 内文件 | 改主方向（非 DeerFlow+Accio 范式） |
| 最小 diff + pytest 证据 | `git push`、`--no-verify` |
| 外发/改价仍 `human_send_required` | 自动发信、自动改价 |
| 未实现 Accio 能力标 `gap`，不删 catalog | 用演讲/七步挤掉飞轮开发 |

## 六、明早 5 分钟（验收）

1. 打开 `.ao-output/night-autodev-YYYY-MM-DD/`：
   - `GATE_REPORT.md` — 机械 pytest 是否绿
   - `MORNING.md` — Agent 写了什么（若无则说明智能层未跑完）
   - `run.log` — 脚本时间线
2. `git status` / `git diff` — 审一眼范围
3. 本地再跑（可选）：

```powershell
Set-Location backend
python -m pytest tests/unit/test_commercial_os_flywheel.py tests/unit/test_accio_sales.py -q
```

4. **满意再提交**；进入 [开发总文档 §8](./商业飞轮OS-开发总文档.md) 的演讲/测试/部署阶段。

## 八、故障排查

| 现象 | 处理 |
|------|------|
| 只有 GATE_REPORT，无 MORNING | 智能层未启动；重贴 AGENT_PROMPT |
| pytest 红 | 先修红再让 Agent 继续；勿 `--no-verify` 提交 |
| Agent 改了很多无关文件 | 回滚；收紧 queue 的 `paths` |
| 循环 /loop 不停 | 对话要求 stop loop，结束 background shell |
