# 接下来怎么做 — 产品 × 营销 × 技术联合行动

> 版本：2026-05-25  
> **前提（对内共识）**：尚未用数据证明「比 6980 GEO 带来更多电话」——**没有成绩，对外只讲在做什么、用什么尺验收，不辩经、不怼人。**  
> **唯一北极星**：客户自有网站带来的 **有效电话/询盘进系统**，可统计、可复盘。

**技术开发顺序**：先完成 [商业飞轮OS-开发总文档.md](./商业飞轮OS-开发总文档.md) §6 P0 验收，再开展本文 §四 演讲彩排与对外 SKU 实机。

## 一、态度（全员）

| 做到 | 不做 |
|------|------|
| 承认差距：朋友 6980 GEO 半个月有电话，我们尚未复现 | 用「功能多 / 222 人 / Sprint 完成」反驳 |
| 用 **后台截图 + 线索表** 说话 | 用路线图、PPT、愿景说话 |
| 对客户：**一起验 30 天 / 12 个月** | 保证排名、保证电话数 |
| 对身体、资金友好：**砍对外承诺，砍并行项目** | 同时冲补贴、全平台、全功能商用 |

## 二、组织方式（不搞虚编制）

**一个小组，一个群主（建议创始人或你指定的 PM），每周 30 分钟站会，只过三张表：**

1. **线索表**（`inquiries` 导出）  
2. **阻塞表**（P0 未上线项）  
3. **对外话术表**（本周能不能对客户说、怎么说）

| 角色 | 负责什么 | 本周交付物 |
|------|----------|------------|
| **产品** | 验收尺、SKU、需求砍刀、彩排脚本 | 一页交付清单 + 禁止对外功能清单 |
| **营销** | 内容、渠道、案例口径、不夸大文案 | 3 平台日更 SOP + 对外一句话 |
| **技术** | P0 上线、来源追踪、报表导出 | HTTPS 演示域 + 手机必填 + 周报 SQL/导出 |
| **运营/创始人** | 第一个试点厂、人审内容、接真实电话 | 1 个签字试点 + 每周复盘纪要 |

> Agency/ECC 编排 **仅对内研发门控**，不对客户宣传「200 多人服务」。

## 三、对外 SKU（先一个，讲清楚）

**主推（唯一）：建材卖货站 · 首年托管版**

- **含**：独立域（HTTPS）+ 租户后台 + 询盘进系统 + 首季内容/GEO 执行清单（人审）  
- **价**：与市场对标 **6980～12800/年**（具体由营销+财务定一档，**先只卖一档**）  
- **验收**：**线索复盘表**（见第五节），不写「保证 N 个电话」  
- **网站地位**：不是附属品，是 **线索唯一落地页与资产载体**

**暂停对外主推**：裸 SaaS 年费、40 平台全量、实验室能力、未挂路由功能。

## 四、技术 P0（4 周内必须上线，否则营销无法验真）

| 序号 | 项 | 验收 | 负责 |
|------|-----|------|------|
| T1 | 1 个 **HTTPS 演示独立域**（可彩排） | 浏览器绿锁 + 表单可提交 | 运维/后端 |
| T2 | 公开询盘 **手机号必填** + 校验 | 无手机提交失败 | 前端+后端 |
| T3 | `source_channel` 全链路（表单/UTM/运营标记） | 后台可按来源筛选 | 全栈 |
| T4 | **线索周报导出**（CSV：日期、手机、来源、状态） | 营销每周五能导出 | 后端 |
| T5 | 发布 Worker **生产 cron** 或明确「首季人工发」 | 站会能说清哪种 | 运维 |
| T6 | UBrain **接真实询盘列表** 生成回复草稿（人点发送） | 租户可演示 1 条 | 后端 |

**禁止**：P0 期间新增顶层菜单、新语言、新国际站插件叙事。

## 五、营销 M0（与产品同尺）

| 序号 | 项 | 验收 |
|------|-----|------|
| M1 | **对外一句话**：「我们帮您把卖货网站做起来，电话进您后台，每月复盘。」 | 全员背诵，禁止功能堆砌 |
| M2 | **试点厂 1 家**（可内部演示厂）签字：同意 30 天验真 | 有书面或微信确认 |
| M3 | **内容 SOP**：每周 ≥3 篇 FAQ 长尾 + 3 平台各 ≥3 条导独立域 | 有链接、有 UTM |
| M4 | **GEO 执行清单**（对标 6980 包，不写超越承诺） | 勾选表：改站、llms、提交入口、复盘 |
| M5 | **案例口径**：无数据前只用「试点中」，禁止「客户都说好」 | 文案审核 |

## 六、产品 P0（砍刀 + 彩排）

| 序号 | 项 | 验收 |
|------|-----|------|
| P1 | **30 分钟彩排脚本**（注册→绑域→发 1 条内容→收 1 条询盘） | 录屏 ≤1 处卡顿 |
| P2 | **禁止对外清单**（40 平台未签、GEO 评分后台、实验室页…） | 销售/代理签字知晓 |
| P3 | **12 个月线索复盘表** 模板（合同附件） | 法务/创始人过目 |
| P4 | **功能→获客** 对照：新需求无格子则不做 | PR 模板强制 |

## 七、时间轴（90 天，只验一件事）

### 第 1～30 天 — 「能接住电话」

- 技术 T1～T4 完成  
- 营销 M2～M4 对试点厂执行  
- **周指标**：`inquiries` 中 **有效手机号条数**（≥0 也要如实记录）  
- **对外**：「我们在用 1 家厂做 30 天验真，结果每周复盘，欢迎监督。」

### 第 31～60 天 — 「来源分得清」

- T5/T6 + 5+5 平台试点（真发或人工等价）  
- 对比：**organic / geo_exec / matrix / manual** 各多少条  
- **对外**：只报试点数据，不泛化全行业

### 第 61～90 天 — 「敢谈值不值」

- 汇总 90 天线索数、响应时效、试点厂主观反馈  
- 决策三选一（数据说话）：  
  - **A** 续推托管版、调价  
  - **B** 首年必须含更多人工执行  
  - **C** 暂停对外扩张，只服务 ≤5 家托管

## 八、站会议程（每周五，30 分钟）

1. 本周 **有效线索数**（环比）  
2. P0 阻塞 **谁、何时解**  
3. 下周 **3 条内容 + 3 条发布** 是否排期  
4. **对外有没有说错话**（夸大、怼客户、怼竞品）  
5. 创始人身体/资金：**是否砍范围**

---

## 九、对客户 / 朋友 / 投资人 — 谦逊话术（统一）

> 「我们之前强调系统能力，是我没把验收尺讲清楚。现在在拿 **1 家试点厂** 做 **30 天验真**：电话是否进后台、来源能否分清。没有数据前，我们不跟任何 GEO 包比嘴炮；有数据后，用 **复盘表** 一起对。若做不过，我们改交付或改价，不找借口。」
