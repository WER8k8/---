# 国内 SEO + GEO：多久能接到「真实询盘电话」

> 版本：2026-05-25  
> 适用：优丁建材 AI-SaaS（租户独立域 + 总站枢纽 + 40 平台 + 询盘 IM）  
> 原则：**只写可核验、可对照行业经验的地板预期**，不写「上线即爆单」。

---

## 一、先给结论（你最关心的）

| 渠道 | 第一个「真实电话/强意向线索」常见区间 | 说明 |
|------|--------------------------------------|------|
| **人工推流**（老客户、微信、抖音/快手口播、1688 私信导到站） | **7～21 天** | 不依赖 SEO；取决于你有没有在推 |
| **百度付费推广**（SEM，系统外） | **3～14 天** | 烧钱最快；与产品代码无关 |
| **国内 40 平台内容矩阵**（真发出去、带落地页+电话） | **14～60 天** | 比纯 SEO 快，但要**真账号、真内容、真更新** |
| **百度自然 SEO（新独立域、建材 B2B）** | **60～120 天** | 行业经验常见 3 个月起量；竞争强则 **6～12 个月** |
| **GEO（豆包/通义/文心等 AI 引用）** | **90～180 天+** | 多为**品牌曝光/间接进站**；**不要指望首月直接来电话** |

**一句话：**  
「系统国内上线」只解决**能接线索的技术能力**；**第一个真实电话**快慢，80% 取决于你有没有**独立域+备案+持续内容+是否在推**，而不是代码 Sprint 是否 84/84。

## 二、和本仓库产品的对应关系（避免误解）

### 2.1 已具备（代码侧）

- 公开询盘：`POST /api/v1/inquiries/public`（姓名、电话、留言、来源渠道）
- 前台吸底条 + 表单：`frontend/components/StickyImBar.vue` → 提交到上述接口
- 租户后台询盘：`/client/inquiries`、超管 `/inquiries/unified`
- SEO 子路由：`/api/v1/seo/*`（矩阵、llms.txt、关键词等）
- GEO 引擎：**主要在超管** `/api/v1/super-admin/geo-engine/*`（评分、监控、告警），面向**运营优化**，不是「一上线 AI 就帮你打电话」

### 2.2 仍挡在「真实电话」前的商用缺口（`docs/module-progress.json` / PM blockers）

| 缺口 | 对询盘的影响 |
|------|----------------|
| **无 HTTPS 演示独立域**（P0-02） | 客户不敢留电话；百度/微信外链信任差 |
| **独立域 Host/SSL 生产 ACME**（P0-01） | 租户站无法稳定用自家域名承接 |
| **40 平台 PM 未签正式表**（P1-10） | 「一键发 40 台」不能对外承诺全自动 |
| **发布 Worker cron 未上生产**（P0-06） | 矩阵内容不会自己跑起来 |
| **IM 全渠道**（P1-01） | 电话之外的企业微信/抖音私信未闭环 |

### 2.3 影响「电话真实性」的产品细节（务必知）

- 吸底表单当前**未单独必填手机号字段**，实现里曾把邮箱字段写入 `phone` 位——**会漏真实号码**，上线前应改为「手机必填 + 验证码/防刷」。
- **GEO ≠ 搜索引擎排名**：国内 GEO 目标是让大模型在回答建材问题时**引用你的品牌/站点**；用户往往再**自己搜或点链接**，电话转化仍走**网站表单/400/企微**。

## 三、百度 SEO（国内自然搜索）— 真实时间轴

### 3.1 新站收录（地板）

| 站点质量 | 首页首次收录 | 内容页开始收录 |
|----------|--------------|----------------|
| 结构清晰、备案正常、站长平台提交 | 约 **3～14 天** | 约 **7～30 天** |
| 一般 | 约 **7～30 天** | 约 **30～60 天** |
| 模板堆砌、频繁改版 | **30 天+** 且不稳定 | 更慢 |

> 参考：行业对百度新站收录周期的公开归纳（非官方承诺）。

### 3.2 收录 ≠ 排名 ≠ 电话

典型顺序：

1. **0～30 天**：收录、结构调整，**几乎无电话**（正常）
2. **30～90 天**：长尾词开始有展现，**偶发 1～3 个表单/私信**（若内容贴「老房换门预算」这类真实问题，优于堆大词）
3. **90～180 天**：部分核心词进前 3 页，**月询盘个位数～十数个**（持续更新前提下）
4. **12 个月+**：建材垂直站才有「月询盘 50+」类稳定量级（社区案例多为**第三年**才稳，前两年常空转）

建材 B2B 特点：**词分散、决策链长、比快消慢**；「1 个月 SEO 来电话」多为销售话术。

### 3.3 什么会明显缩短周期

- **老域名/有历史收录**的独立域（比全新域快 1～2 个月）
- **总站枢纽页**合规导流（权重继承，需法务与百度规范）
- **每周 2～4 篇**解决具体采购问题的文章（非产品说明书复读）
- **百度站长平台**主动推送 + **ICP 备案** + **HTTPS**
- **本地/品类词**优先（如「廊坊 铝型材 厂家」）而非全国大词

## 四、国内 GEO — 真实预期

| 阶段 | 可能发生的事 | 与「电话」关系 |
|------|----------------|----------------|
| 0～30 天 | 配置 llms.txt、FAQ、结构化数据；后台跑 GEO 评分 | **几乎无电话** |
| 30～90 天 | 部分问题回答中出现品牌/链接片段 | **间接**：用户自行搜索或进站 |
| 90～180 天 | 竞品监控、告警、内容迭代后引用率略升 | 仍**弱于 SEO+SEM**；勿单独押宝 |

**诚实结论：** 2026 年国内 GEO 仍偏**实验与品牌占位**；**第一个真实电话**不要按 GEO 排期，应按 **SEO + 人工推流 + 可选 SEM** 排期。

## 五、「40 平台国内发布」和 SEO 的区别

| | SEO（百度） | 40 平台矩阵 |
|--|-------------|-------------|
| 流量性质 | 主动搜索、意向偏高 | 推荐流/关注流，需内容钩子 |
| 首电典型 | 60～120 天 | **14～60 天**（若日更+挂电话/企微） |
| 系统现状 | API 较全 | Worker 有，**生产 cron + 平台账号授权**未齐 |

矩阵要快：**真人发、真电话、真案例视频** → 比等百度收录现实得多。

## 六、结合你当前处境（廊坊、无执照、无独立域、卖货少）

若 **2 周内** 只做到「本地 docker 上线、无备案域名、无人推」：

- **预期第一个真实电话：无保证，可能 0**（正常）

若 **30 天内** 做到：

1. 租户/个体 **1 个备案域名 + HTTPS**  
2. 吸底条 **手机必填** + 400/企微同屏  
3. **每天 1 条** 短视频/图文导流到落地页（哪怕先 3 个平台）  

- **预期：7～30 天内有第一个电话的概率明显上升**（仍非 100%）

**政府补贴与 SEO 无关**：无锡 10～30 万评审看的是**销售与团队**，不是「系统里有多少 SEO 功能」。

## 七、建议排期（可写进商业计划，勿写进对客户的承诺）

| 时间 | 动作 | 电话预期 |
|------|------|----------|
| 第 1 周 | HTTPS 域、备案、询盘手机必填、百度站长提交 | 仅人工推可能有 |
| 第 2～4 周 | 5+5 平台试点真发；20 篇长尾 FAQ 文 | 矩阵 **0～2** 个弱线索 |
| 第 2～3 月 | SEO 长尾词 + 可选小额 SEM | SEO **0～5** 个/月 |
| 第 4～6 月 | GEO 监测迭代 + 总站枢纽 | 叠加，仍低于 SEM |
