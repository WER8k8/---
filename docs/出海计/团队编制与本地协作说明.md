## 二、日常怎么开发？（任意 IDE，免费可用）

**固定五步（与 Cursor / VS Code / 灵码 / Trae 无关）：**

```text
① 任意编程 IDE 打开本仓库
② 终端 A：backend → uvicorn 127.0.0.1:8001 --reload
③ 终端 B：frontend/admin → npm run dev（5173）
④ IDE 内置浏览器 → http://localhost:5173/login
⑤ 超管登录 → /admin、创始人诊断等直接调
```

| 项 | 值 |
|----|-----|
| 后端端口 | **8001**（管理端 Vite 代理） |
| 管理端 | **http://localhost:5173** |
| 本地 `.env` | `OAUTH_DEV_BYPASS=true`、`JWT_SECRET_KEY`、创始人三行见下 |

**不必付费 Cursor**；**VS Code 免费**即可。线上服务器**不用 SSH 日常改代码**，本机调好再部署。
