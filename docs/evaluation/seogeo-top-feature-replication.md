## 三、P0 功能详细设计

### 功能1: 多模型品牌排名对比

**功能描述**: 输入品牌名/关键词，一键查询该品牌在 ChatGPT、DeepSeek、豆包、元宝、通义、文心、Kimi 等 AI 模型中的"认知度排名"。

**实现逻辑**:
```
1. 用户输入关键词 → POST /api/v1/super-admin/geo-engine/check
2. 后端并行查询6个AI模型API
3. 每个模型返回: {status: indexed/not_indexed, rank: 排名位置, summary: 模型知道的品牌信息摘要}
4. 前端展示: 模型卡片矩阵 + 收录状态标签 + 排名位置 + 详细摘要
```

**界面设计**: 已实现于 `/admin/geo-engine`（需增强：添加排名位置、模型官方搜索链接按钮）

**技术可行性**: ✅ 已开发完成，需小幅增强。后端用 httpx 并行请求各模型 API。

**实现周期**: 0.5天（增强现有页面）

---

### 功能2: 关键词收录率仪表盘

**功能描述**: 可视化展示品牌在各大AI模型中的收录状态变化趋势。

**实现逻辑**:
```
1. 每次查询结果存入 Redis (geo_engine:{keyword}:{timestamp})
2. 前端请求 GET /api/v1/super-admin/geo-engine/trend?keyword=xxx&days=30
3. 返回每日收录率数据 → 前端渲染折线图
4. 仪表盘顶部显示: 总收录率、收录AI模型数、趋势箭头(↑/↓)
```

**界面设计**:
```
┌────────────────────────────────────────────────┐
│  收录率仪表盘                                    │
│  ┌──────┐ ┌──────┐ ┌──────┐ ┌──────┐           │
│  │ 67%  │ │ 4/6  │ │ ↑12% │ │ 最佳: │           │
│  │收录率 │ │AI模型│ │周增长│ │DeepSeek│          │
│  └──────┘ └──────┘ └──────┘ └──────┘           │
│  [折线图: 30天收录率变化趋势]                      │
└────────────────────────────────────────────────┘
```

**技术可行性**: ✅ 后端已有 check_keyword + history API，前端需增加趋势图组件。

**实现周期**: 1天

### 功能4: GEO评分系统

**功能描述**: 对品牌关键词的AI模型收录表现进行综合评分(0-100分)。

**评分维度**:
```
总分 = 收录率分(40%) + 排名分(30%) + 正面率分(20%) + 稳定性分(10%)

- 收录率分: 收录的AI模型数 / 总模型数 × 40
- 排名分: 各模型平均排名位置映射为分数 (第1位=30分, 第10位=10分)
- 正面率分: 正面提及占比 × 20 (需NLP情感分析)
- 稳定性分: 近30天收录率标准差映射
```

**技术可行性**: ⚠️ 排名分和正面率分需要额外的模型API调用。初期可仅计算收录率分 + 稳定性分。

**实现周期**: 1.5天
