# 出海计 App — 产品规格（租户商家端 · 必做）

> **产品名称（定稿）**：**出海计**  
> **副标题（应用商店）**：建材出海 AI 助手 —— Powered by 优丁建材 OS  
> **英文名 / 包名建议**：`ChuHaiJi` · `com.youding.chuhaiji`  
> **「出海季」**：仅作 **年度营销/活动品牌**（如「2026 出海季发布会」），**不是** App 名称  
> **版本**：V1.0 · 2026-05-24  
> **主册章节**：`docs/产品经理-开发文档.md` §2.8

## 一、命名说明（PM · 运营 · 营销共识）

| 名称 | 是否用作 App | 理由 |
|------|----------------|------|
| **出海计** | ✅ **正式** | 「计」= 计策、计划；贴合 **出海参谋 + UBrain**，B2B 老板易理解 |
| **出海季** | ❌ App 名 | 「季」偏活动/促销（双11 季），适合 **拉新战役、线下峰会**，不适合日常工具名 |
| **优丁助手** | 功能品牌 | App 内 **AI 对话** 仍叫「优丁助手」，与 Web 一致 |
| **优丁建材 OS** | 平台品牌 | 公司/融资叙事；App 图标下写「出海计」 |

## 二、代码扫描：预留了什么

### 2.1 已有

| 类型 | 路径 | 用途 |
|------|------|------|
| 买家 H5 | Nuxt `/mobile/*` | 访客，**不是** 出海计 |
| IM | `GET /api/v1/mobile/im-routing` | 可复用 |
| 产品聚合 | `products_mobile.py` | 需修双前缀 → `/api/v1/mobile/product/{id}` |
| 租户 API | `/api/v1/client/dashboard` 等 | **出海计主数据源** |
| 登录 | `/api/v1/auth/*` | JWT 通用 |
| 通知 | `/api/v1/notifications` | 需扩展 Push |

### 2.2 必建

- `GET/POST /api/v1/app/v1/*` BFF（home、devices、config）
- Push（询盘 / 发布失败 / SSL 将过期）
- Capacitor（或 Uni-app）安装包
- UBrain `POST /api/v1/ubrain/chat`

## 三、豆包式体验（4 Tab）

| Tab | 名称 | 内容 |
|-----|------|------|
| 1 | **助手**（默认） | UBrain 对话 + 芯片：回询盘 / 发一条 / 蓝海 / 能不能出口 |
| 2 | **今日** | 待办 + 出海参谋 1 条蓝海 |
| 3 | **发布** | 简化发布枢纽 + 进度 |
| 4 | **我的** | 套餐、域名、邀请、设置 |

## 四、发布路线

| 阶段 | 周期 | 交付 |
|------|------|------|
| App-0 | 4～6 周 | PWA + `/client` 移动助手页；修 mobile API |
| App-1 | 8～12 周 | BFF + Push + Capacitor；应用宝 / TestFlight |
| App-2 | +12 周 | 语音、离线询盘列表 |

**硬依赖**：Web Client 四支柱 + UBrain v1（AI-M0）。
