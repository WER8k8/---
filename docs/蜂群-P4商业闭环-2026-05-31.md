## W15 支付宝异步通知

**路由** `POST /api/v1/payment/notify/alipay`

- 接收支付宝 `application/x-www-form-urlencoded` 回调
- RSA2 验签（`PAYMENT_STRICT_VERIFY=1` 时强制）
- 成功响应纯文本 `success`（失败 `failure`）
- `process_alipay_notify` 支持 `TRADE_SUCCESS` / `TRADE_FINISHED`，并校验 `total_amount`

**配置**

```
ALIPAY_NOTIFY_URL=https://你的域名/api/v1/payment/notify/alipay
```

## W16 落地页线索 CRM

**数据库** migration `036_inquiry_assigned_to` → `inquiries.assigned_to`

**服务** `inquiry_lead_assignment_service.py`

- `source_channel=platform_landing` 时自动轮询分配（最少负载）
- 候选人：`PLATFORM_LEAD_ASSIGNEE_IDS` 或 role ∈ sales/admin/super_admin
- 飞书卡片通知（`FEISHU_WEBHOOK_URL`）
- 销售角色登录仅看自己负责的询盘

**API**

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/inquiries/assignees` | 可分配人员列表 |
| PUT | `/inquiries/{id}/assign` | 管理员手动改派 |

**前端** `views/inquiries/index.vue`

- 改用 `/inquiries/unified`
- 来源渠道筛选（含 platform_landing）
- 展示负责人列
