# 优丁AI SaaS - 自定义域名配置指南

## 什么是自定义域名？

自定义域名，就是**让您的客户通过您自己的公司域名访问网站**，而不是一串复杂的系统地址。

**举例：**
- 您的公司网站是：`www.abc-building.com`
- 优丁系统分配的是：`customer.youding-saas.com`

配置完成后，客户在浏览器输入 `www.abc-building.com`，就能看到您的专属网站。这对品牌信任度和专业形象至关重要。

---

## 前提条件

在开始之前，请确认以下两点已经就绪：

- [x] **您已经拥有一个域名**（例如 `www.abc-building.com`）
- [x] **您能登录域名的 DNS 管理后台**（通常在您购买域名的注册商那里，如阿里云、腾讯云、GoDaddy、Namecheap 等）

> 如果您还没有域名，可以在阿里云、腾讯云、GoDaddy 等平台购买，价格通常为每年几十元。

---

## 配置步骤

### 方法一：CNAME 记录（推荐）

这是最常用的方式，配置简单，并且即使我们的服务器 IP 发生变化，您的域名也不会受影响。

**第一步：登录 DNS 管理后台**

登录您的域名注册商网站，找到 **DNS 管理** 或 **DNS 解析设置**。不同平台入口名称略有不同：

| 平台 | 常见入口名称 |
|------|-------------|
| 阿里云 | 域名管理 -> DNS 设置 -> 解析设置 |
| 腾讯云 | 域名管理 -> 解析设置 |
| GoDaddy | Domains -> DNS Records |
| Namecheap | Domain List -> Manage -> Advanced DNS |

**第二步：添加 CNAME 记录**

在 DNS 解析设置页面，点击 **添加记录** 或 **新增解析**，然后填写以下信息：

| 字段 | 填写内容 |
|------|---------|
| **主机记录** | `www` |
| **记录类型** | `CNAME` |
| **记录值** | `saas.youding.com` |
| **TTL** | 保持默认（或选择 600） |

**具体操作示例：**

```text
主机记录（Name/Host）：    www
记录类型（Type）：         CNAME
记录值（Value/Target）：   saas.youding.com
TTL（缓存时间）：          自动 / 600
```

**第三步：保存生效**

点击 **保存** 或 **确认**。DNS 解析在全球生效需要一定时间，通常在 **5 到 30 分钟** 内完成。

---

### 方法二：A 记录

如果您需要将根域名（如 `abc-building.com`，不带 `www`）指向我们，可以使用 A 记录。

**第一步：登录 DNS 管理后台**（同方法一）

**第二步：添加 A 记录**

| 字段 | 填写内容 |
|------|---------|
| **主机记录** | `@`（或留空，视平台而定） |
| **记录类型** | `A` |
| **记录值** | `123.123.123.123` |
| **TTL** | 保持默认 |

```text
主机记录（Name/Host）：    @（或留空）
记录类型（Type）：         A
记录值（Value）：          123.123.123.123
TTL（缓存时间）：          自动 / 600
```

> **提示**：配置根域名（不带 www）后，建议同时添加一条 `www` 的 CNAME 记录（方法一），这样用户无论输入哪种地址都可以正常访问。

---

## 验证方法

配置完成后，可以通过以下方式验证是否生效：

### 方法一：在优丁后台验证

1. 登录优丁 AI SaaS 后台
2. 进入 **SaaS租户 -> 域名管理**
3. 点击该域名旁边的 **"验证 DNS 配置"** 按钮
4. 系统会自动检测 DNS 解析是否正确

### 方法二：使用命令行验证

打开电脑上的命令提示符（CMD）或终端，输入：

```bash
ping www.abc-building.com
```

如果返回的 IP 地址是 `123.123.123.123`（或显示 CNAME 解析到了 `saas.youding.com`），说明配置成功。

### 方法三：在线工具验证

使用 [DNS 查询工具](https://mxtoolbox.com/DNSLookup.aspx)（如 mxtoolbox.com），选择 **CNAME Lookup**，输入您的域名，查看解析结果是否正确。

## 常见问题

### DNS 生效需要多久？

DNS 解析在全球生效通常需要 **5 到 30 分钟**，少数情况下可能需要 **24 小时**（取决于域名注册商的 TTL 设置）。如果您等待超过 24 小时仍未生效，请检查配置是否正确。

### 如何配置根域名？

如果想让用户直接访问 `abc-building.com`（不带 `www`），需要：

1. 添加一条 **A 记录**：主机记录为 `@`，记录值为 `123.123.123.123`
2. 建议同时添加一条 **www 的 CNAME 记录**，确保两种方式都能访问

在优丁后台添加域名时，可以分别添加 `abc-building.com` 和 `www.abc-building.com`。

### 如何配置多个域名？

您可以在优丁后台添加多个域名指向同一个网站。例如：

- `www.abc-building.com`
- `abc-building.com`
- `www.abc-building.cn`

每个域名都需要在 DNS 管理后台配置对应的解析记录。

### 配置后网站无法访问怎么办？

请按以下步骤排查：

1. **检查 DNS 配置是否正确**：确认主机记录、记录类型、记录值填写无误
2. **等待 DNS 生效**：刚配置完可能需要几分钟到几小时
3. **清除浏览器缓存**：有时浏览器缓存了旧的 DNS 结果
4. **使用 ping 命令检查**：确认域名解析到了正确地址
5. **联系客服**：如以上步骤均无效，请联系优丁 AI SaaS 技术支持

### 配置 CNAME 还是 A 记录？

**推荐使用 CNAME 记录**。因为如果后期我们的服务器 IP 发生变化，CNAME 记录会自动跟随，而 A 记录需要您手动更新。CNAME 是更稳定、更省心的选择。
