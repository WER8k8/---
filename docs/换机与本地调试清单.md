# 换机与本地调试清单

> **原则**：任意编程 IDE + **内置浏览器** 打开 `http://localhost:5173/login` → 登录超管后台直接调。  
> 与 Cursor / VS Code / 灵码 / Trae 无关，只要 IDE 能开终端 + 内置浏览器即可。

---

## 一、换机前（旧电脑备份）

### 必拷（Git 里没有）

| 文件/目录 | 说明 |
|-----------|------|
| `backend/.env` | 密钥、JWT、AI Key、创始人微信配置等 |
| `backend/youding_dev.db` | 本地 SQLite 数据（若要保留测试账号/数据） |
| 桌面或其它位置的 **`.env.prod`** | 若单独保存过生产配置 |

可用 U 盘、网盘、微信文件助手；**不要**把 `.env` 提交到 Git。

### 建议 Git 推送

```powershell
cd "C:\Users\97907\Desktop\UJ\website CodeBuddy"
git status
git add -A
git commit -m "换机前备份"
git push
```

### 不必整盘拷贝

- `node_modules/`、`frontend/admin/node_modules/` — 新电脑 `npm install` 即可  
- `.codegraph/` — 新电脑可 `codegraph init -i` 重建  
- `__pycache__/`、`.pytest_cache/` — 可忽略  

### 可选备份

- `C:\Users\97907\.cursor\` 里个人规则、技能（若仍用 Cursor）  
- Obsidian / 出海计笔记（若在桌面 `出海计` 文件夹）

## 二、新电脑安装（一次性）

| 软件 | 用途 | 备注 |
|------|------|------|
| **Git** | 拉代码 | https://git-scm.com/ |
| **Python 3.11** | 后端 | 勾选 Add to PATH |
| **Node.js 20 LTS** | 管理端 `npm` | 含 npm |
| **编程 IDE（任选一个）** | 写代码 | **VS Code 免费** 或 Cursor / 其它 |
| **Docker Desktop** | 可选 | 要用 `docker compose` 时再装 |

后端依赖（在新电脑第一次）：

```powershell
cd backend
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
pip install gmssl>=3.2.2
```

## 三、新电脑拉项目

```powershell
# 示例路径，按你习惯改
cd C:\Users\97907\Desktop\UJ
git clone <你的仓库地址> "website CodeBuddy"
cd "website CodeBuddy\backend"
copy .env.example .env
```

把**旧电脑备份的 `backend/.env`** 覆盖到新电脑的 `backend/.env`（或手工合并密钥行）。

至少确认本地开发这几行存在：

```env
ENVIRONMENT=development
DEBUG=true
DB_TYPE=sqlite
OAUTH_DEV_BYPASS=true
FRONTEND_URL=http://localhost:5173
OAUTH_REDIRECT_URI=http://localhost:5173/login/oauth-callback
JWT_SECRET_KEY=<32位以上随机串>

FOUNDER_WECHAT_BIND_KEY=qq979072138
FOUNDER_WECHAT_OPENID=wechat_qq979072138
FOUNDER_ADMIN_USERNAME=qq979072138
```

若需要旧数据：把 `youding_dev.db` 拷到 `backend/` 下。

## 四、日常调试（任意 IDE，固定五步）

```text
① IDE 打开文件夹：website CodeBuddy
② 终端 A — 后端（端口必须是 8001）
③ 终端 B — 管理端 Vite
④ IDE 内置浏览器 → http://localhost:5173/login
⑤ 超管登录 → /admin、创始人诊断等直接点
```

**终端 A：**

```powershell
cd backend
$env:PYTHONPATH = (Get-Location).Path
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m uvicorn app.main:app --host 127.0.0.1 --port 8001 --reload
```

**终端 B：**

```powershell
cd frontend\admin
npm install
npm run dev
```

**内置浏览器：**

- VS Code / Cursor：`Ctrl+Shift+P` → **Simple Browser: Show** → `http://localhost:5173/login`

## 六、上线与换机的关系

- **换机**只影响你本机开发环境。  
- **线上服务器**不用为换机重装；域名、`.env.prod` 在服务器或运维文档里，与笔记本无关。  
- 你以后仍按：**本机 IDE + 内置浏览器调试 → 满意后再部署**，不必 SSH 上云改代码。
