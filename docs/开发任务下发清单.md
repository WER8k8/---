## 十一、风险与升级路径

| 风险 | 影响 | 缓解 |
|------|------|------|
| `routes/seo.py` 与 `api/v1/seo` 路径冲突 | A-03 延期 | 先删 stub 再挂新路由，一次性 PR |
| seo-backend 与 FastAPI 双写 | B 发布逻辑分裂 | B-06 必须出 ADR，禁止双端各改一套 |
| 40 平台清单未定 | B-03 阻塞 | PM 先出 5+5 试点，余量迭代 |
