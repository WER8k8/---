## 一、SaaS 仪表盘设计核心原则

### 1.1 视觉层次（Visual Hierarchy）

现代 SaaS 仪表盘遵循 **"信息密度递减"** 原则：

```
┌─────────────────────────────────────────────────────────┐
│  ① 顶部：身份 + 全局操作（搜索、通知、用户）    ← 最高优先级  │
├──────────┬──────────────────────────────────────────────┤
│          │  ② KPI 卡片区：4-6 个核心指标          ← 一眼可见  │
│  侧边栏   │  ③ 主图表区：趋势 + 分布              ← 聚焦分析  │
│  导航     │  ④ 操作区：待办 + 快捷入口            ← 行动导向  │
│          │  ⑤ 底部区：日志 + 告警                ← 辅助参考  │
└──────────┴──────────────────────────────────────────────┘
```

### 1.2 设计关键词

| 维度 | 站酷参考风格 | 优丁目标 |
|---|---|---|
| **布局** | 侧边栏 + 顶栏 + 卡片网格 | 保持现有 248px 侧边栏，优化内容区 |
| **配色** | 低饱和度 + 高对比重点色 | 薄荷绿主色 + 角色色区分 |
| **卡片** | 玻璃拟态 / 微凸起 / 极简线框 | 统一为玻璃拟态（已有基础） |
| **数据可视化** | 渐变面积图 + 圆角柱状图 + 环形进度 | 引入 ECharts 替换 CSS 手绘图表 |
| **动效** | 微交互 + 页面过渡 + 骨架屏 | 保持 0.12s 过渡，增加骨架屏 |
| **密度** | 紧凑但不拥挤，留白呼吸感 | max-width 1440px，24px 网格间距 |
