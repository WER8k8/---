# 河北廊坊产业带实地调研宪章 · PM-07 × 市场调研

> **签发**：项目经理 + 产品策略  
> **适用**：大城县及廊坊周边 **建筑相关** 产业带（保温、防火/防腐涂料、板材、辅材、河间配套等）  
> **原则**：**产品太多，不能靠研发在 JSON 里猜** — 由 **调研人员实地/catalog 调研** 后入库，系统再消费。

---

## 一、为什么要调研（给老板一句话）

大城不光有岩棉玻璃棉，还有 **钢结构防火涂料、防腐涂料、网格布、阴阳角护角** 等大量附属品。  
预设词库只能是 **种子**；**完整品类清单必须来自产业带调研**，否则开发信和 SEO 会对不上厂子的真实货。

---

## 二、两套数据，别混

| 数据 | 谁维护 | 用途 |
|------|--------|------|
| **租户产品库** | 每个客户自己录 | 开发信、建站、内容 — **唯一可信货源** |
| **产业带目录（调研成果）** | 调研组录入 → PM 审核合并 | 开户推荐、SEO 词库种子、代理话术、行业模板 |

客户产品 **不在** 产业带目录里 → **不拦**（见产品库优先）；  
产业带目录 **不全** → **不假装全**，界面/文档标明「调研更新中」。

## 三、调研范围（廊坊基本盘）

### 3.1 地理

| 层级 | 重点 |
|------|------|
| 县级 | **大城县** |
| 镇/园区 | 留各庄、权村、广安、北魏、尚文等（调研时逐镇补全） |
| 关联 | **河间**（橡塑、密封、管道配套，可并行调研） |
| 上级 | 廊坊市、河北省产业带政策/园区名单 |

### 3.2 品类（必须分栏调研，不可只写「建材」）

| 品类 ID | 中文 | 调研要点 |
|---------|------|----------|
| `main_insulation` | 保温主材 | 岩棉/玻璃棉/橡塑/聚氨酯/XPS/酚醛… |
| `steel_fire_coating` | **钢结构防火涂料** | 薄型/厚型/超薄型；钢构/隧道；检测报告、耐火极限 |
| `fire_coating_general` | 防火涂料（非钢构） | 饰面型、混凝土防火等 |
| `anti_corrosion_coating` | **防腐涂料** | 环氧、聚氨酯、氟碳、管道/设备防腐 |
| `panel_system` | 板材 | 夹芯板、净化板、冷库板 |
| `finish_accessories` | **饰面/抹灰辅材** | **网格布、耐碱网格布、阴阳角、护角条、分隔条、网格带** |
| `fixing_accessories` | 固定件 | 保温钉、锚固件、电焊网 |
| `mortar_adhesive` | 砂浆胶粘 | 粘结/抹面/抗裂砂浆 |
| `pipe_support` | 管道支架托架 | 管托、支架、管壳 |
| `packaging` | 打包辅材 | 胶带、缠绕膜、打包带 |
| `hejian_rubber` | 河间橡塑密封 | 密封条、垫片、软接头（河间专项） |

**每类至少调研**：常见品名 10+、规格说法、是否出口常见、典型镇/园区集中度。

## 四、调研人员交付物（固定格式）

### 4.1 单次调研包（必填）

使用模板：

- 表格版：`docs/templates/industry-belt-field-survey-sheet.md`  
- 机器可读：`docs/templates/industry-belt-survey-deliverable.schema.json`  
- 填写示例：`backend/app/data/industry_belt_survey_samples/dacheng_2026Q2_draft.json`

每条产品记录：

```text
品名 | 所属品类 | 常见规格/参数 | 集中产地(镇/园区) | 是否适合外贸 | 备注/证据(厂名、展会、目录页)
```

### 4.2 证据要求（防假调研）

至少满足 **其一**：

- 实地园区/店铺招牌或产品册照片（存 `docs/surveys/evidence/`，不进 git 大文件可放网盘路径）  
- 县域 B2B 平台/目录截图 + URL + 日期  
- 3 家以上工厂口径一致的品名/规格  

**禁止**：只靠抖音关键词臆测；禁止复制竞品 SaaS 品类树冒充大城调研。

### 4.3 合并入库流程

```text
调研员填 deliverable JSON
    → PM/产品审核（品类是否重复、名称是否口语化）
    → 运行 scripts/merge-industry-belt-survey.py（合并进 industry_belt JSON）
    → SEO 组决定是否同步 seed 词库（dacheng_seo_keywords.json）
    → 更新 pm-dacheng-saas-framework-inventory.md 的「调研批次号」
```

## 七、多 AI 大模型初稿（PM 另派）

品类太多时，**PM-07 先派多模型 AI 调研**，核心问题：

> **大城县 + 河间市这一带，都有哪些跟建筑相关的产品名字？主材和附属配套都要列。**

- 派工单：`docs/pm-langfang-industry-belt-ai-research-charter.md`  
- Prompt：`docs/templates/industry-belt-ai-research-prompt.md`  
- 执行：`python scripts/run-industry-belt-ai-research.py`（默认大城+河间全量品名）  

AI 初稿默认 `pm_review.pending`，**必须**经 PM + 实地 spot-check 后才可 merge。
