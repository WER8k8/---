# 优丁建材 AI-SaaS -- 生产上线检查清单

> 版本: v2.0 | 最后更新: 2026-05-21
> 适用: Docker Compose 生产环境部署

---

## 一、部署前检查 (Pre-Flight)

### 1.1 服务器环境

- [ ] 操作系统: Ubuntu 22.04+ / Debian 12+ / CentOS Stream 9+
- [ ] CPU: >= 4 核 (推荐 8 核)
- [ ] 内存: >= 8 GB (推荐 16 GB)
- [ ] 磁盘: >= 50 GB 可用 (SSD 推荐)
- [ ] Docker Engine >= 24.0 已安装并运行
- [ ] Docker Compose >= v2.20 已安装
- [ ] 防火墙开放端口: 80 (HTTP) / 443 (HTTPS) / 22 (SSH)
- [ ] 时区已设置为 Asia/Shanghai

### 1.2 SSL 证书

- [ ] 域名 DNS 已解析到服务器公网 IP
- [ ] SSL 证书已通过 Let's Encrypt 签发 (或上传商业证书)
- [ ] 证书文件位于 `deploy/ssl/fullchain.pem` 和 `deploy/ssl/privkey.pem`
- [ ] 证书有效期 >= 30 天
- [ ] `deploy/ssl/renew-cert.sh` 已配置 crontab 自动续期

### 1.3 数据库

- [ ] PostgreSQL 15 已准备 (容器化或独立实例)
- [ ] 数据库已从 SQLite 迁移到 PostgreSQL
- [ ] 数据备份策略已就绪
- [ ] `backend/alembic/` 迁移脚本已检查无冲突

### 1.4 环境变量 (.env.prod)

- [ ] `JWT_SECRET_KEY` 已设置为 >= 32 字符强随机值
- [ ] `DB_PASSWORD` 已设置强密码
- [ ] `REDIS_PASSWORD` 已设置强密码
- [ ] `MINIO_ACCESS_KEY` / `MINIO_SECRET_KEY` 已配置
- [ ] `SMTP_PASSWORD` 已配置 (邮件通知)
- [ ] `AI_NVIDIA_API_KEY` 已配置 (AI 服务)
- [ ] 所有 `your-*` 占位符已替换为真实值
- [ ] `DEBUG=false` (生产模式)
- [ ] `.env.prod` 文件权限 600 (仅所有者可读写)

### 1.5 前端构建

- [ ] Admin SPA (`frontend/admin/`) 已 `npm run build` 构建完成
- [ ] Nuxt 主站 (`frontend/`) 已生成 SSG 产物
- [ ] 前端环境变量中的 API 地址指向正确的生产域名

## 二、部署中 (Deployment)

### 2.1 启动服务

- [ ] `docker compose -f docker-compose.prod.yml --env-file .env.prod up -d`
- [ ] 所有容器状态为 `Up` (docker compose ps)
- [ ] 无容器处于 restarting 状态

### 2.2 数据库迁移

- [ ] `docker compose run --rm backend alembic upgrade head` 执行成功
- [ ] 种子数据已初始化: `docker compose run --rm backend python seed.py`
- [ ] 管理员账号已创建

### 2.3 Nginx 配置

- [ ] `docker exec youding-nginx nginx -t` 显示 successful
- [ ] `docker exec youding-nginx nginx -s reload` 无错误
- [ ] HTTP 80 端口正常响应

- [ ] 多语言切换正常 (zh / en / de / fr / ...)

### 3.3 功能验证

- [ ] 首页加载时间 < 3 秒

## 五、紧急回滚方案

如果部署后出现严重问题:

```bash
# 1. 回滚到之前版本
docker compose -f docker-compose.prod.yml down
git checkout <之前正常版本>
docker compose -f docker-compose.prod.yml --env-file .env.prod up -d

# 2. 数据库回滚
docker compose run --rm backend alembic downgrade -1

# 3. 从备份恢复数据库
gunzip < backup_最新.sql.gz | docker exec -i youding-postgres psql -U youding_admin youding_prod
```

## 六、常用运维命令

```bash
# 查看服务状态
docker compose -f docker-compose.prod.yml ps

# 查看实时日志
docker compose -f docker-compose.prod.yml logs -f --tail=100 backend

# 重启单个服务
docker compose -f docker-compose.prod.yml restart backend

# 进入容器调试
docker exec -it youding-backend /bin/bash

# 手动备份数据库
docker exec youding-postgres pg_dump -U youding_admin youding_prod | gzip > backup_$(date +%Y%m%d_%H%M%S).sql.gz

# 更新 SSL 证书
sudo certbot renew --dry-run  # 先测试
sudo certbot renew            # 正式续期
docker exec youding-nginx nginx -s reload

# 清理旧镜像和卷 (释放磁盘)
docker system prune -a --volumes -f
```
