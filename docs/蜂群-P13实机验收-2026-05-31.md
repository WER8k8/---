## ngrok 配置

1. 打开 [ngrok Authtoken](https://dashboard.ngrok.com/get-started/your-authtoken) → **Your Authtoken** → Copy  
2. 复制 `.env.ngrok.local.example` → `.env.ngrok.local`，填入 token（**已在 .gitignore，不会上传**）  
3. 执行：

```powershell
powershell -ExecutionPolicy Bypass -File scripts/setup-ngrok.ps1
powershell -ExecutionPolicy Bypass -File scripts/start-ngrok-tunnel.ps1
```

**密钥安全**

- token 只保存在本机：`%LOCALAPPDATA%\ngrok\ngrok.yml` 与 `.env.ngrok.local`  
- **不要** commit、不要发聊天、不要贴 Issue  
- 若曾在聊天里发过错误密钥，到 ngrok 控制台 **Reset Authtoken** 轮换
| strict_signed_notify | 后端需严验签 + 密钥 | `PAYMENT_STRICT_VERIFY=1` + `PAYMENT_WEBHOOK_SECRET=...` 后重启 API |
| alipay_rsa_signed | 沙箱密钥 | 配置 `ALIPAY_APP_ID` / 私钥 / 公钥 |

严验签 + 签名正向（P13 W42）：

```powershell
# 重启 backend 前设置
$env:PAYMENT_STRICT_VERIFY='1'
$env:PAYMENT_WEBHOOK_SECRET='your-staging-secret'

  --base-url http://127.0.0.1:8001 `
```
