## 一、结论（给项目经理）

1. **大城县**在全国公开报道中被定位为 **「全国最大绝热节能材料生产销售基地」**，官方与媒体 repeatedly 提到 **30+ 系列、上百品种**；单靠研发穷举不现实，**联网只能得到「主干品类 + 代表企业产品线」**。  
2. **防火/防腐涂料、封堵材料**在大城有 **独立产业集群**（留各庄等），与保温主材并列，品类含钢构防火涂料、电缆防火涂料、防腐漆、阻火包、堵料、隔板等。  
3. **网格布、保温钉、砂浆**等多为 **外墙保温系统辅材**，大城产业链配套销售常见，但公开来源以 **「保温四大类 + 工程配套」** 为主，辅材需调研员按厂补齐规格（克重、阴阳角型号）。  
4. **河间**公开信息侧重 **橡塑密封、保温管防腐、岩棉/硅酸铝**，与 **「中国保温城」** 规划并存；与大城形成 **主材（大城）+ 密封/管道/防腐配套（河间）** 组合。

## 二、大城县 — 产业概况（联网）

| 项目 | 公开信息 |
|------|----------|
| 定位 | 国家火炬绝热节能材料特色产业基地；「中国绿色保温建材之都」 |
| 2024 产值 | 约 **150 亿元**（河北园区招商网等转引） |
| 企业规模 | 绝热材料企业 **170+**（2024 廊坊政府稿）；规上 **69 家** |
| 从业人员 | 约 **1.8万～3.2万**（不同稿件口径） |
| 市场份额（报道） | 岩棉、玻璃棉约 **40%**；橡塑约 **50%～60%** |
| 集群镇区 | **留各庄**（核心）+ **权村、里坦、广安、臧屯** + 经开区（「一区六园」含绝热节能材料产业园） |

## 五、与大城龙头企业的产品线对照（联网）

| 企业 | 公开产品线（节选） |
|------|-------------------|
| **华美节能科技集团** | 橡塑绝热、离心玻璃棉、岩棉、XPS；深冷/耐高温橡塑、环保玻璃棉等 |
