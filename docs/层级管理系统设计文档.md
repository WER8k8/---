# 层级管理系统设计文档

## 系统概述

本系统实现"超管→省级代理→市级代理→租户"的四级层级管理架构，包含管理后台和官网展示两大部分。

## 系统架构

### 四级角色结构

| 层级 | 角色代码 | 角色名称 | 主要职责 | 权限范围 |
|------|----------|----------|----------|----------|
| L1 | super_admin | 超管 | 平台侧最高运营主体，可管全租户、全能力与向下划拨 | 全局数据管理、所有功能 |
| L2 | l2_provincial | 省级代理 | 管理下辖市级代理与商业条款，不触碰平台根密钥 | 本省数据、下级管理 |
| L3 | l3_city | 市级代理 | 深耕矩阵与地域词，服务多个官网租户 | 本市数据、下级管理 |
| L4 | tenant | 官网租户 | 维护自己的官网内容、产品与日常获客 | 自有数据、内容管理 |

## 技术实现方案

### 前端技术栈

- 框架：Vue 3 + TypeScript
- UI组件：Ant Design Vue
- 状态管理：Pinia
- 路由：Vue Router
- 样式：Tailwind CSS + SCSS

### 后端技术栈

- 框架：FastAPI
- ORM：SQLAlchemy
- 数据库：SQLite (Dev) / PostgreSQL (Prod)
- 认证：JWT

### 数据流转规则

```
超管 → 省级代理 → 市级代理 → 租户
    ↓          ↓          ↓
  全局数据  省级数据  市级数据  租户数据
```

### 权限边界控制

1. **数据隔离：** 各层级只能访问自己权限范围内的数据
2. **操作限制：** 不同层级有不同的操作权限
3. **审计日志：** 所有操作都有完整的日志记录
