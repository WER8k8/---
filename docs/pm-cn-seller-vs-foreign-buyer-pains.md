## 一、一句话：外商要啥 vs 国人怕啥

| 外商（买家）心里问 | 国人（卖家）心里怕 |
|-------------------|-------------------|
| 这厂靠谱吗？有检测吗？ | 我不会英文，讲不清楚 |
| 规格对不对？能出口吗？ | 我写的参数他看不懂 |
| 多少钱？MOQ？多久发货？ | 我不会报价、不懂 Incoterms |
| 发邮件/WhatsApp 有人回吗？ | 时差、看不懂邮件、不知道咋回 |
| 网站像不像皮包公司？ | 我没有像样的英文站 |
| 和 Alibaba 上别家有啥不同？ | 我只会在国内平台，不会自己找客 |

**产品北极星**：让 **不会英语的老板**，也能用 **真实产品库 + 真实厂子素材**，在外商面前 **看起来专业、沟通有草稿、询盘不丢** — **不造假、不包排名、不替老板乱承诺价格**。

## 三、文化/心理层（PM 容易忽略）

| 痛点 | 说明 | 产品对策 |
|------|------|----------|
| **怕丢面子** | 英文差，怕回复不专业 | **AI 草稿 + 老板中文确认 → 再发英文** |
| **怕 responsibility** | 怕报错价、怕承诺交不了 | 报价模板带 **「需确认交期」**；禁止一键乱发 |
| **信熟人不信系统** | 爱用微信、不爱用 CRM | 询盘 **可转发微信摘要**；系统仍留底 |
| **重关系轻合同** | 先聊再谈价 | 询盘阶段 **MEDDPICC 轻量**，不逼填 20 项 |
| **外商重邮件轻寒暄** | 要 direct、要 specs | 开发信 **短、带参数表链接**，不长篇中文式客气 |

## 六、给销售/代理的「国人面对外国人」三句话

1. **看见**：英文站 + 英文视频 + 能被 Google/YouTube/AI 搜到 — 不用您会英语。  
2. **沟通**：洋询盘 **翻译成中文** 给您看；您 **中文说意思**，系统帮您 **写英文回复草稿**。  
3. **诚实**：参数来自 **您录的产品库**；不包排名、不包一定成交；您 **点发送** 才出去。

| 合规 | 禁止包排名、证书夸大 |
| 前端 | Client 全中文操作、结果英文化 |

## 八、验收（PM-07 签字用）

阶段 A 对 **10 家大城试点厂** 抽问：

1. 您 **不会英语**，能不能在系统里 **发出一条英文产品视频/页面**？  
2. 来 **英文询盘**，能不能看到 **中文摘要** 并 **中文确认后回复**？  
3. 能不能说清 **今年几个有效洋询盘**（数字可为 0，不能假）？

**三题有两题「能」** → 国人↔外商痛点 **阶段性过关**。
