🔄 三大核心数据流

销售飞轮 (Sales Flywheel)

  1. 内容生产 → SEO/GEO 发布
  2. 搜索引擎收录 → 排名提升
  3. 访客进入 → 行为追踪
  4. 线索捕获 → 邮件培育
  5. 转化签约 → 数据回流优化

UBrain 闭环 (AI Decision Loop)

  1. Agent 决策 (track_decision)
  2. 任务执行 (track_execution)
  3. 效果反馈 (track_feedback)
  4. 归因分析 (attribution)
  5. 模型调优 → 下一轮决策

向量管道 (Vector Pipeline)

  1. 内容分块 / Embedding 生成
  2. Qdrant 向量 upsert
  3. 语义搜索 / 混合检索
  4. Neo4j 知识图谱关联
  5. RAG 增强生成 → 答案输出
