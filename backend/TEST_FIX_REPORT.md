## 主要修复内容

### 1. 统一响应格式问题
**问题**：API返回 `{code: 0, data: {...}}` 而不是 `{code: 200, data: {...}}`

**解决方案**：
- 修改测试断言：`assert data["code"] == 200` → `assert data["code"] == 0`
- 使用 `api_data()` 辅助函数解包响应

### 2. 路由路径不匹配
**问题**：健康检查路由在 `/api/v1/health` 而不是 `/health`

**解决方案**：
- 修改测试路径：`/health` → `/api/v1/health`

### 3. 语法错误
**问题**：
- JSON对象中的键缺少引号：`quantity: 1000` → `"quantity": 1000`
- pytest装饰器缩进错误：`@pytest.fixture` 缩进不正确

**解决方案**：
- 修复JSON语法错误
- 修复pytest装饰器缩进

### 4. 导入路径问题
**问题**：`unify_response_middleware` 中没有 `success_response` 函数

**解决方案**：
- 修改导入路径：`from app.core.unify_response_middleware` → `from app.core.response`
