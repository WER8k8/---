🛡️ 企业级安全体系升级

当前 8.5 → 目标 9.6 +1.1
1JWT 全面迁移到 HttpOnly Secure Cookie
从 sessionStorage 迁移到 HttpOnly Cookie 的完整方案：
  • 后端新增 /auth/session 端点，Set-Cookie 时指定 HttpOnly + Secure + SameSite=Strict + Path=/
  • CSRF Token 采用 Double Submit Cookie 模式（Cookie 存 csrf_token，请求头 X-CSRF-Token 带同样的值）
  • 前端移除所有 token 存储逻辑，axios 自动携带 Cookie
  • WebSocket 认证改为握手时校验 Cookie + 生成一次性 connection_token
  • 提供 30 天过渡期：同时支持 JWT Header 和 Cookie，逐步废弃 Header 方式

2国密算法替换为 GmSSL 认证库
  • 替换 gm_crypto.py 自研实现为 gmssl-python（国密局认证算法库）
  • 添加 SM2 密钥管理：密钥分离存储，生产环境使用 HSM 或 KMS
  • 字段加密增加密钥轮换机制：encryption_key_version 字段标记每条记录使用的密钥版本
